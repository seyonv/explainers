4 · Attention and the KV cache

19 cards on how attention is computed without an N×N matrix, and how the KV cache is shrunk, paged, shared, tiered and scheduled. The core papers are walked section by section: online softmax, FlashAttention 1 and 2, GQA, MLA, PagedAttention, SGLang's RadixAttention and Mooncake. This is course 4 of the Fast LLM inference series (it needs The math of serving an LLM; Writing fast GPU kernels helps; see the map). Labs in labs/: numpy reference implementations and simulators that run on a Mac, one Colab notebook and one rented-H100 vLLM script (neither run by the author). Click a card to read it; ← → to page.

Prerequisites: Needs perf-2. perf-3 helps with the FlashAttention kernel details. Each card says what it builds on, so you can see where it's safe to jump around.
