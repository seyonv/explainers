In one breath

The paper makes two claims. First, in 21,438 public SWE-bench runs, the gap between "I fixed it" and "it's fixed" comes mostly from honest misses and untested claims, not from agents contradicting their own failing tests (0.17% of claims). Second, in a controlled, pre-registered experiment where every run carries a test the agent can't fix, it measures what compaction does to the final report and to the tests: whether agents claim false success, blame the environment for fixable failures, or edit the tests. Each card builds one link in that chain, and a link only counts once its evidence was checked against the world: re-run tests, the diff, held-out labels, a registered analysis.

The one relationship: claim ⇐ evidence ⇐ card

There is no formula here. A paper is a chain of claims, and each claim is only as strong as the evidence under it. Read each row as "the paper may say this, because of that, which you build on this card".

The words people use

Confirmatory vs exploratory

Confirmatory: a hypothesis and test written down before the data (here H2, and H1a/H1b). Exploratory: anything found by looking. Both get reported; only the first gets to say "supported".

Pre-registration and addendum

A dated, committed plan of outcomes, analysis and stopping rule. Changes are new dated sections, never edits; here the commits are the timestamps.

Prefix, branch, arm

A prefix is the agent's own run up to the trigger; each arm continues it once (d0, d1-codex, …). A branch is one such continuation, so arms differ only after the trigger.

Status inflation vs tampering

Inflation: the summary upgrades failed to passed (0/80 in the baseline). Tampering: the agent changes the tests so the failure goes away (17.5% → 37.5%). The paper now expects the second, not the first.

When this doesn't apply. This route fits a small, cheap, controlled study by one person with API access, where runs cost cents and the outcome can be checked by re-running tests. It is the wrong route when the outcome needs human judgement for every item (the labeller can't be validated by a frozen-prompt check alone), when you need the real production harness rather than a transplanted prompt (Codex with an OpenAI model compacts server-side, so the copied prompt isn't what it runs), or when the effect only appears on models you can't call (no Claude model here). In those cases the observational half, or a smaller qualitative study in the real CLIs, is the honest paper.

Understand and remember

  • A claim belongs in the paper only with a registered design, a world-checked measurement and a result → the baseline's tampering lead has the first two but not a confirmatory result → it can motivate H2 but not be reported as the finding
  • Natural self-contradiction is 0.17% of claims → a causal study of it would need about 5,110 tasks → forcing the failing state and pairing within prefix bring it to tens of tasks and a sweep capped at $120
  • Live runs reach the trigger only 73% of the time and arms diverge before it → branching from the agent's own prefix makes every dose-1 branch compact in the same state as its control → the dose contrast is within-prefix
  • The tampering hypothesis was found by looking at pilot data → testing it on the same tasks would be a forking path → addendum 3 tests it on 40 fresh tasks with a pre-set one-sided rule
  • detail that matters The labeller is validated on held-out items (65/66 finals) but every held-out hand label is one class → κ is uninterpretable and recall rests on the 20 dev positives → a human second annotator is still owed before submission

Reference only

5 · Predict commit to an answer before revealing

Suppose H2 comes out supported in gpt-5.4-mini but flat in gpt-5.5. Before reading the analysis card, predict which row of the chain gets a new caveat and which registered test speaks to it.

Reveal

Row 8 gets reported pooled as registered, with the per-model estimates beside it as exploratory; the model-difference test (family M: the H2 contrast in gpt-5.5 minus that in gpt-5.4-mini) is the registered way to say whether they differ. Row 10's limitations gain 'the effect may depend on the model', since only two OpenAI models were run.

6 · Apply use the model, don't restate it

Done when: Your table names H1a (P1, d1 vs d0, Holm with H1b) as the registered test, cites the baseline's P1 rates (0/40, 1/40, 0/40) as motivation only, notes the floor (0/40 has an upper Wilson bound of 8.8%), and marks the result pending.

Hint
