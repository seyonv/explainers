Study path · Day 5 · one page

Build the scheduler

Day 5 of the inference study plan: the part of an engine that decides, on every step, which requests run and how much memory each gets. It covers Part 3 of the request-scheduler course, where you build one in Python, then maps it onto vLLM's real scheduler. Everything is inline: just scroll. Ticks are shared with the checklist version.

What today uses, and why

Day 2 explained why a server batches, and Day 4 showed one under load. Day 5 opens the part of the engine that makes every batching decision, by building one in Python.

Request scheduler course, Part 3Ten cards that build a scheduler step by step, with a reference solution and tests.
The gentlest way into an engine's code: every decision is small, written out and simulated with numbers you can rerun.
Serving station 3, the restThe part of the station Day 2 left for later.
It maps what you built onto vLLM's real scheduler, so the toy and the real thing line up.
Serving project 4: a toy engineAn optional 30-hour build.
The same ideas as a working engine for a small real model, checked against vLLM.
By the end of today, you'll be able to
  • State the interface of a request scheduler and the states a request moves through, from waiting to finished.
  • Walk through one call of step(): which requests run, how many tokens each gets, and what happens when memory runs out.
  • Explain how a paged block manager hands out KV memory, and why preemption can thrash.
  • Compare scheduling policies (first come first served, shortest job first, priority) on latency and fairness.
  • Explain prefix caching: how a shared prompt is found and reused instead of being prefilled again.
  • Map each part of vLLM's scheduler onto the reference solution.
How to use this page
  1. Scroll. The bar pinned at the top always says what the current step is and how to read it: Skim Read Pretest Checkpoint Optional Task.
  2. Each phase with a checkpoint opens with a Before you read box: prime, then try the checkpoint cold.
  3. Every card has two study boxes. The green Prime box at its top is read before the card. Study this card at its bottom is done after it, on Read steps only; Skim steps hide it.
  4. Tick Done as you finish a step. Take a break after each checkpoint.
  5. “Go deeper” sources stay closed. Open them only for a card whose questions you missed; Show here loads one inline.
