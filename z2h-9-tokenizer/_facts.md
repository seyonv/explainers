# Shared facts: Let's build the GPT tokenizer (z2h-9-tokenizer)

Every card writer reads this file before writing. Reuse these values exactly.

## This course
Lecture 8 of Zero to Hero: tokenization is its own stage with its own training set and algorithm (byte pair encoding). Build the GPT-2/GPT-4 tokenizer from scratch with minbpe, and trace many of the strange behaviours of LLMs back to it.
- Lecture: L8. 14 concept cards plus `big-ideas.html` and `_overview.html` (written after the concept cards).
- **Running example / conventions for this course:** The Colab example string (300 GPT-2 tokens vs 185 GPT-4); the first training text (533 characters = 616 bytes, top pair 'e ' ×20, 616 → 596 after one merge); 20 merges on the full post: 24,597 bytes → 19,438 tokens (1.27×); GPT-2 vocab 50,257 = 256 + 50,000 + 1; cl100k 100,277; minbpe at vocab 512 on the Taylor Swift page: 2.36× basic, 2.13× regex (map-C).
