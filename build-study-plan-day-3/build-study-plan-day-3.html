Build an LLM study plan · Day 3

The GPT model

Day 3 of the Build an LLM path: Raschka chapter 4. Assemble layer norm, the feed-forward network, shortcut connections and attention into a transformer block, stack twelve of them into GPT-2's 124M shape, and make it generate (badly: it isn't trained yet).

By the end of all of this, you'll be able to
  • Code a transformer block and the full GPT model, and count its parameters.
  • Explain what layer norm and shortcut (residual) connections are for.
  • Explain why an untrained model's text is gibberish, and what generating one token involves.
The same routine every phase
  1. Prime (5 min): read the phase intro and the green Prime box of any card in it.
  2. Code, don't copy. Type each book listing, run it, and print the shapes.
  3. Revisit the LLM basics card linked under a step when the code stops making sense.
  4. Say it back at the end of each day, closed book, before checking.
