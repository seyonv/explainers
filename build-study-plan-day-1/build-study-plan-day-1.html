Build an LLM study plan · Day 1

Tools, and what training does

Day 1 of the Build an LLM path: just enough PyTorch to read and write the book's code, and what “training” actually does to a model's numbers, built up from one neuron. You need your copy of Raschka's Build a Large Language Model (From Scratch) and Python with torch installed.

By the end of all of this, you'll be able to
  • Create tensors, run a small network, and write a PyTorch training loop with a data loader, without looking anything up.
  • Explain what a gradient is and what one optimizer step does to a weight, with numbers.
  • Say why next-token prediction is trained with cross-entropy, and what its value means.
  • Train a tiny language model (the bigram) yourself and sample from it.
The same routine every phase
  1. Prime (5 min): read the phase intro and the green Prime box of any card in it.
  2. Code, don't copy. Type each book listing, run it, and print the shapes.
  3. Revisit the LLM basics card linked under a step when the code stops making sense.
  4. Say it back at the end of each day, closed book, before checking.
