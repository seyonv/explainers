Core reference: CS interviews, mapped

Start here. This card shows the ten courses built from ljeng/cheat-sheet: what each one covers, which to read first, which ones to read for which interview, and where every section of the source ended up.

In one breath

The source guide is a terse set of interview notes: problem statements, one-line solutions and dense paper summaries. This series turns every section of it into 181 cards across 10 courses, plus one overview card per course. Every code example is Python you can run. The source's Java and C++ were rewritten, not transliterated. Where the source has only a heading (all of Operating Systems, all of Financial Mathematics, and a few smaller gaps), the card is written from standard references and says so in its footer. Every number is either computed exactly or measured on an Apple M3, and the card says which.

When this doesn't apply

This is interview preparation built from one person's study guide, not a textbook. It follows the source's choice of topics and problems, so it leaves out much of what a course would cover (proofs of correctness, security, most of a networking or databases syllabus) and goes deep wherever the source's author did.

Cards marked as supplemented are ours: the topic comes from the source's heading, but the content, examples and numbers were chosen for this series from the references each footer names. Timings are from one laptop and will differ on yours; the ratios are what carry over.
