What the source got wrong

Every real error the 181 cards found in the cheat-sheet, in one place: what the source said or did, what is correct, and how we checked. Each card also shows the fix where it happens, in a muted line under the code or the answer.

In one breath

We found 30 real errors on 27 of the 181 cards. Most are code that crashes or won't compile as printed, usually a name used outside its scope. Eight are wrong answers: four probability results, a shortest-path problem solved with a spanning-tree algorithm, and three that fail only on rare inputs or repeated calls. Five are silent: no crash, but the code mutates its input, leaks memory or reads memory it shouldn't. That leaves six places where a paper or a textbook fact is stated backwards. The notes are otherwise sound: at least 30 cards say outright that they checked the source's code or answer and found it right, most of them against a brute force.

The errors, by course

"Ran it" means the source's own code, ported line for line where it wasn't Python, run under Python 3.10. "Compiled" means Apple clang 17 on the author's M3. "Brute force" means compared with a slow, obviously correct version on random inputs.

Unclear or mislabelled, but not wrong

These don't change an answer. The cards fix or explain them, and they are listed here so you don't count them as errors.

  • C++ that works by luck. Insertion sort (swap(a[j], a[--j])) and palindrome cuts (reads and increments j in one expression) rely on an evaluation order C++ doesn't promise; both are right under clang. State-machine DP uses vector without including it.
  • Code that isn't there. Five graph cards call a code/graph.py that is missing from the repo (representations, flood fill, BFS, bipartite, Dijkstra); two import the third-party sortedcontainers; bit arithmetic negates with a multiplication the problem forbids.
  • Typos and labels. τ called "e" and 1\cwnd for 1/cwnd (delay); WARS expanded wrongly (quorums); "Savich" and u ∈ I (query complexity); a dropped term in a delta rule (semi-naïve); "zero one" outputs and pseudocode tagged cpp (MapReduce); C++ tagged java (interfaces); a Weibull filed under Gamma (Weibull); a density printed with the wrong sign (deductibles); 68.26/95.44/99.74% for 68.27/95.45/99.73% (kσ, normal); footnotes that point to the wrong note or to none.
  • Loose wording. p99 as "the worst 1%" (backpressure); "consumers can't exceed partitions" when the extras just sit idle (load balancing); ZooKeeper in memory "to avoid" GC (service discovery, our reading); a proof direction mislabelled (I-confluence); a self-contradicting sentence on block size (anti-caching); the adjoint method described by its forward half only (autodiff tape); a figure and its text describing two different share policies (GPU fair share); StringBuffer where modern javac emits StringBuilder or invokedynamic (compilers); the log base left unstated (algorithm vs hardware); Type I and II errors under the opposite convention (averages); "20% headroom" with two readings (sizing).
  • Right answer, assumption unstated. Whether a negative binomial counts failures or trials (negative binomial); a nonsmoker death rate the table implies but never gives (Bayes); "doors lock behind him", which hints at a variant with a different answer (first-step analysis). The chuck-a-luck formula on averages looks off but is right: −17/216, checked over all 216 rolls.

How much of the source is right

27 of 181 cards (15%) correct a real error; 154 don't. About 30 more flag something from the list above, and at least 30 say outright that the source's code or answer was checked and is right, often against a brute force on thousands of random cases. A few also make correct code leaner without calling it wrong: the quicksort stack depth, the suffix automaton's memory, bidirectional BFS growing the smaller side.

The errors cluster where you'd expect in hand-kept notes: code that was probably never run (most of cs-3's rows are name errors), and one-line summaries of long papers (cs-5 and cs-6). The worked answers in probability are mostly right; four aren't. 25 of the 154 (all of cs-7 and cs-10) had no source content to check, because the heading was empty and the card was written from references.
