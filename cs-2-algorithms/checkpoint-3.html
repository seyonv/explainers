Checkpoint 3: four ways to compare strings

Ties together Knuth–Morris–Pratt, rolling hash, Manacher's algorithm and the suffix automaton: what each one remembers so it never re-reads a character, and which question each is built to answer.

How to use this page. Close the four cards. Answer each question in writing, in full sentences, before opening its Check. A wrong or shaky answer isn't a failure; it tells you exactly which section to reopen. The questions are mixed on purpose, so you have to work out which idea applies before you can answer.

1 · Mixed retrieval

  1. which concept?A network appliance must flag one fixed 64-byte signature in a byte stream. It can't buffer or rewind the stream, and attackers choose the traffic. Which algorithm, and which two of its properties decide it?
    Check
    • KMP: the text index only moves forward, so each byte is read once and never needed again
    • its O(n + m) bound is deterministic: no hashing, so no input can force collisions
    • a fixed-(B, p) rolling hash could be attacked; a suffix structure would index the wrong thing (the stream, not the signature)

    Missed it? Reopen KMP, "No backing up" and "Should you write KMP in real code?".

  2. ABABCABAB has lps = [0, 0, 1, 2, 0, 1, 2, 3, 4]. What is its smallest period, and why does lps[m − 1] give it?
    Check
    • period = m − lps[m − 1] = 9 − 4 = 5
    • a border of length b means the string equals itself shifted by m − b in the overlap
    • the longest border gives the smallest such shift

    Missed it? Reopen KMP, the "✓ KMP" cell and "The one idea: a border".

  3. which concept?In a 45-minute interview you're asked for the longest substring that appears at least twice in a 10⁵-character string. Which approach do you write, and what do you do about collisions?
    Check
    • rolling hash + binary search on the length: "a repeat of length L exists" is monotone, each test is an O(n) pass of window hashes into a set
    • with 10⁵ windows and one modulus near 10⁹, the birthday effect predicts about 5 colliding pairs
    • use a double hash (≈ 5 × 10⁻⁹ expected collisions) with a random base, or verify candidate repeats by comparing characters

    Missed it? Reopen rolling hash, "Why one modulus is not enough here".

  4. On "a" × 1,000, expanding around every centre makes 1,000,000 checks and Manacher makes 1,999. Which quantity only moves one way in Manacher, and how does that bound the checks?
    Check
    • r, the right edge of the rightmost palindrome, never moves left
    • every successful check pushes r one step right, so there are at most about 2n successes
    • each centre adds at most one failing check: O(n) in total

    Missed it? Reopen Manacher, the complexity line under the code.

  5. which concept?A search service must answer millions of "does t occur in this 10⁶-character document?" queries, with |t| up to 50, against a document that never changes. Which structure, and what does each query cost?
    Check
    • a suffix automaton of the document, built once in O(n)
    • each query walks arrows from the start: O(|t|), independent of the document's length
    • KMP per query would reread the whole document every time; the price here is memory (up to 2n − 1 states)

    Missed it? Reopen suffix automaton, the "✓ Suffix automaton" cell and "Is it always the tool?".

  6. Shortest Palindrome glues s + "#" + reverse(s) and reads the last lps value. What does that value mean, and what goes wrong for aaa without the #?
    Check
    • it's the longest prefix of s that equals a suffix of reverse(s): the longest palindromic prefix
    • without the separator, aaaaaa has a border of 5 > len(s) = 3: the border runs across the join
    • with aaa#aaa it's 3, so nothing is added: aaa is already a palindrome

    Missed it? Reopen KMP, "The source's other use: Shortest Palindrome".

  7. In the suffix automaton for banana, state 9 holds ana and na. What do those two strings have in common that puts them in one state, and why does that make ana the answer to Longest Duplicate Substring?
    Check
    • both end at exactly positions 4 and 6: equal endpos sets share a state
    • two end positions means both occur twice; the state's len (3) is its longest string
    • it's the new state's link at the last step, and len(link) = 3 is the best over all steps

    Missed it? Reopen suffix automaton, "The ten states".

3 · Project: one string, four tools

What it reinforces: the border table and linear search (KMP), window fingerprints and binary search on a length (rolling hash), mirror radii (Manacher) and endpos states (suffix automaton), all on the same input, so you can see which question each one answers.

Use s = "abracadabra" (11 characters) and the functions from each card's code/ file, or your own. In about 40 lines of glue:

  1. Find. Build lps for abra and for s itself. Find every occurrence of abra with KMP, counting comparisons, and compare with naive search. Give s's smallest period.
  2. Repeat, by hashing. Find the longest duplicate substring with rolling hash + binary search on the length. Confirm with rabin_karp(s, "abra") where it occurs.
  3. Repeat, by automaton. Build the suffix automaton of s. Report the number of states and transitions against the 2n − 1 and 3n − 4 bounds, the longest repeat, and the number of distinct substrings via Σ (len − len(link)). Check the count with a brute-force set.
  4. Palindromes. Run Manacher: the longest palindromic substring and the count of palindromic substrings (Σ (p + 1) // 2). Check the count by brute force.
  5. Shortest palindrome. Use KMP's s + "#" + reverse(s) trick to find the shortest palindrome you can make by adding characters in front of s. How long is the palindromic prefix it keeps?
Done when: steps 2 and 3 agree on the longest repeat, every brute-force check matches, and for each of the five questions you can say in one sentence why that tool (and not another from this part) was the natural one. Then compare with the check.
Check: the numbers (computed with the cards' own code files)
  • lps(abra) = [0, 0, 0, 1]; lps(s) = [0, 0, 0, 1, 0, 1, 0, 1, 2, 3, 4]. abra occurs at 0 and 7; KMP makes 13 comparisons, naive search 16. Smallest period 11 − 4 = 7.
  • Longest duplicate substring: abra; rabin_karp finds it at [0, 7].
  • Automaton: 12 states (≤ 21) and 17 transitions (≤ 29); longest repeat abra; 54 distinct substrings, matching the brute-force set.
  • Manacher: the longest palindrome is aca (ada ties); 13 palindromic substrings (11 single letters plus aca and ada), matching brute force.
  • The glued string's last lps is 1: only a is a palindromic prefix. The shortest palindrome is arbadacarb + abracadabra, 21 characters.
