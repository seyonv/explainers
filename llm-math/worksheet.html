This is the course's output. With a calculator and these pages, run one full training step of the tiny transformer: forward, loss, backward and update. Then check your numbers against PyTorch's. Plan on about two hours.

How to use it
  • Work top to bottom. Each grid has one cell filled in; if yours differs there, stop and fix that step before going on.
  • Keep 4 decimals. Round only when you write a number down.
  • Rows are tokens: row 0 is the, row 1 cat, row 2 sat. A layer is xWxWxW, with WWW shaped (in, out).
  • Short on time? Do row 2 only, since it's the row that sees all three tokens, plus all of x0x_0x0​, AAA and dzdzdz.
  • The answer key is on the last pages.
