Random walks

Also called the simple random walk, the drunkard's walk or gambler's ruin. Take one step of +1 or −1 at a time. In finance it is the discrete model under Brownian motion and option pricing, and the maths of betting with or against a small edge. Running example: start with $10, bet $1 at a time, stop at $0 or $20.

In one breath

Add up independent ±1 steps. After n steps the average position moves by n × (edge), but the typical distance from that average grows only like √n. So a small edge is invisible over a hundred bets and decides everything over ten thousand. For the $10 → $20 game, a fair coin gives a 50% chance of doubling. At 49% per bet, the chance falls to 40%.

E[bets] = (i − N·h)/(q − p) from the martingale Sn − (p − q)n; a fair game takes i(N − i) = 100 bets from $10. Same edge, bigger stakes in bet units: the longer game lets the drift catch up with the noise.

In Python

from fractions import Fraction as F
import random

def ruin(i, N, p):
    """P(reach N before 0) from i, and E[steps]."""
    q = 1 - p
    if p == q:                      # S_n and S_n^2 - n
        return F(i, N), i * (N - i)
    r = q / p                       # r**S_n is a martingale
    h = (1 - r**i) / (1 - r**N)
    return h, (i - N * h) / (q - p)

def simulate_ruin(i, N, p, walks, seed=0):
    rng = random.Random(seed)
    wins = steps = 0
    for _ in range(walks):
        x = i
        while 0 < x < N:
            x += 1 if rng.random() < p else -1
            steps += 1
        wins += x == N
    return wins / walks, steps / walks

h, t = ruin(10, 20, F(49, 100))
print(f"{float(h):.4f} {float(t):.1f}")     # → 0.4013 98.7
print(simulate_ruin(10, 20, 0.49, 100_000)) # → (0.40126, 98.52676)
# the __main__ demo in code/ also prints
#   n=   10,000 drift=   -200 sd=100.0 E|S| fair= 79.79 vs  79.79
#   drift = sd when n = 4pq / (p-q)^2 = 2,499

Time O(1) for the formula (O(log N) multiplications with exact Fractions). The simulation costs O(walks × E[steps]): 10⁵ × 98.5 ≈ 10⁷ coin flips, and its error shrinks only like 1/√walks.

Why it beats the alternatives

✗ "0.49 is basically 0.5"

True for one bet, false for a game. From $10 to $20 the chance falls to 0.40; from $100 to $200 it's 0.018, not 0.5. The edge compounds over ~100 and ~4,800 bets.

✗ Distance grows like n

A fair walk after 10,000 steps is typically 80 away from the start, not thousands. Assuming linear spread overstates risk over long horizons by a factor of √n.

✗ Just simulate

10⁵ walks give 0.4013 ± 0.0016: three digits for 10⁷ coin flips, and each extra digit costs 100× more. Fine as a check, poor as the answer.

✓ Drift n, noise √n, ruin formula

Two scaling laws tell you whether the edge matters (n versus n* = 2,499), and one closed form gives the exact odds in O(1). Use simulation only to check.

Is a random walk the right model for prices?

Only as a first approximation. Prices multiply rather than add, so the standard model makes the log price the random walk, and its continuous limit is geometric Brownian motion (next card). The √n rule is why volatility is quoted per √time: daily σ × √252 gives annual σ, as on the returns card. Bachelier (1900) first modelled prices this way.

Where it fails: real returns have fat tails and volatility clustering, so steps aren't identical, and Lo and MacKinlay (1988) rejected the random walk for weekly US index returns. It also ignores bet sizing: the ruin formula assumes a fixed $1 stake. Betting a fraction of the bankroll instead is the Kelly question. With a negative edge, fewer and bigger bets are better: staking all $10 on one bet wins 0.49 of the time, against 0.4013 in $1 steps (bold play, shown optimal for unfavourable games by Dubins and Savage).
