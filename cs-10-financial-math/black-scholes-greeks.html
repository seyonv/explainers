Black–Scholes and the Greeks

Also called Black–Scholes–Merton (BSM), the closed-form European option price; the Greeks are its sensitivities: delta, gamma, vega, theta, rho. The source guide names Financial Mathematics but has no page for it, so this card follows Hull and the 1973 paper, using the course's shared contract: S₀ = 100, K = 100, r = 5%, σ = 20%, T = 1 year.

In one breath

If the stock follows geometric Brownian motion with a known volatility, you can copy a European option's payoff exactly by holding a changing number of shares and some cash. So the option must cost what that copy costs, and that cost has a formula. Each Greek is one partial derivative of the formula: how much the price moves when one input moves.

The copy of the call is 0.6368 shares ($63.68) financed by borrowing $53.23. Put–call parity holds for any model; it's a free check on your code. N(−x) = 1 − N(x), which gives the put's 0.4404 and 0.3632.

The five Greeks, two examples each

Think of the option price as a car's position: delta is its speed as the stock moves, gamma is how fast that speed changes, and theta, vega and rho are how the position shifts when the clock, the weather (volatility) or the road (rates) change.

Delta is the slope, gamma is the bend

Call price from the formula at S = 60…140 in steps of 5 (computed). The curve bends above its tangent everywhere; that curvature is gamma, and it's why a delta hedge drifts.

In Python

import math

def norm_cdf(x):
    return 0.5 * (1 + math.erf(x / math.sqrt(2)))

def norm_pdf(x):
    return math.exp(-x * x / 2) / math.sqrt(2 * math.pi)

def d1_d2(s, k, r, sig, t):
    d1 = (math.log(s / k) + (r + sig**2 / 2) * t) / (sig * math.sqrt(t))
    return d1, d1 - sig * math.sqrt(t)

def price(s, k, r, sig, t, call=True):
    d1, d2 = d1_d2(s, k, r, sig, t)
    disc_k = k * math.exp(-r * t)            # K e^(-rT)
    if call:
        return s * norm_cdf(d1) - disc_k * norm_cdf(d2)
    return disc_k * norm_cdf(-d2) - s * norm_cdf(-d1)

def greeks(s, k, r, sig, t):
    """Call Greeks in closed form (vega per 1.00 of sigma)."""
    d1, d2 = d1_d2(s, k, r, sig, t)
    return {
        "delta": norm_cdf(d1),
        "gamma": norm_pdf(d1) / (s * sig * math.sqrt(t)),
        "vega": s * norm_pdf(d1) * math.sqrt(t),
    }

Time O(1) · Space O(1) per price: a log, a square root and two erf calls. That's why desks use it to re-price thousands of options a second.

Why it beats the alternatives

✗ Binomial tree

Converges to the same price, but slowly: the CRR tree is off by −0.197 at N = 10, −0.020 at 100 and −0.002 at 1,000 steps, so error shrinks only like 1/N.

✗ Monte Carlo

The discounted payoff has a standard deviation of about 14.7, so 10⁶ paths still leave ±0.015 of noise, and Greeks from noisy prices are noisier still.

✗ Bump every Greek

Works for any model, but costs 2–3 re-prices per Greek and depends on h: at h = 10⁻⁷ gamma comes out −0.71 instead of 0.0188.

✓ Closed form

Exact in one call, with every Greek as a formula of its own. It also gives the hedge (hold N(d1) shares) along with the price.

Tree errors from the binomial-pricing card's crr(). The 14.7 is the standard deviation of e^(−rT)·max(ST − K, 0) over 10⁶ simulated paths (numpy, seed 0); ±0.015 = 14.7 / √10⁶.

Is Black–Scholes the right price?

Only for its own assumptions: a constant σ, lognormal prices with no jumps, no dividends, European exercise, and hedging in continuous time at no cost. Real markets break all of these. The market quotes a different implied σ for each strike (the volatility smile), so traders use the formula mostly as a translator between price and σ, not as a forecast. American puts can be worth exercising early, so they need a tree or a PDE solver, and path-dependent payoffs such as Asian options need Monte Carlo.

A common mix-up: N(d2) = 0.5596 is the risk-neutral probability that the call ends in the money, not the real-world one. N(d1) = 0.6368 is the delta, not a probability of anything you'd bet on.
