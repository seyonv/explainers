Sharpe ratio, beta and CAPM

Also called the reward-to-variability ratio (Sharpe), market sensitivity (beta) and the security market line (CAPM). Three numbers that ask different questions: how much return per unit of total risk, how much market risk, and what return that market risk should earn. Used in every fund report and most quant interviews.

In one breath

Sharpe divides a strategy's average excess return by how much it wobbles. Beta is the slope you get when you regress a stock's returns on the market's: how many percent it moves when the market moves 1%. CAPM says only that slope is paid for, so a stock's expected return is the risk-free rate plus beta times the market's premium.

Worked example 1: a daily Sharpe, annualized

daily mean 0.05%, sd 1%, rf = 0 → 0.0005 / 0.01 = 0.05 per day annual mean 0.0005 × 252 = 12.6% annual sd 0.01 × √252 = 15.87% → 0.126 / 0.1587 = 0.794 same thing: 0.05 × √252 = 0.794 (rf = 5%/yr: (0.126 − 0.05) / 0.1587 = 0.479)

Numbers illustrative. The mean scales with N but the sd with √N, so the Sharpe scales with √N: a daily 0.05 is an annual 0.79. For scale, Sharpe (1994) takes a stock market with a 6% mean excess return and 15% sd: 0.06 / 0.15 = 0.40 a year.

Worked example 3: the CAPM line

With rf = 5% and a market expected return of 12.6% (the daily 0.05% above), the premium is 7.6%. Every beta then gets a required return on one straight line. Rates illustrative.

A: 0.05 + 1.3 × (0.126 − 0.05) = 0.05 + 0.0988 = 14.88% B: 0.05 + 0.5 × (0.126 − 0.05) = 0.05 + 0.0380 = 8.80%

A stock that returns more than its point on the line has positive alpha; less, negative alpha.

The words, two examples each

Think of a boat on a tide. Beta is how far your boat rises when the tide rises; the rest of its bobbing is your own waves (idiosyncratic risk), which a fleet of boats averages away. Examples are the synthetic stocks in the code below: 1,000 days, seed 0, true betas 1.3 and 0.5.

In Python

import math
import numpy as np

def sharpe(mean, sd, rf=0.0, periods=252):
    return (mean - rf) / sd * math.sqrt(periods)

def beta_alpha(stock, market):
    dm = market - market.mean()
    ds = stock - stock.mean()
    beta = (dm * ds).sum() / (dm * dm).sum()   # cov / var
    alpha = stock.mean() - beta * market.mean()
    return beta, alpha

def capm(beta, rf, market_return):
    return rf + beta * (market_return - rf)

rng = np.random.default_rng(0)                  # 1,000 days
mkt = rng.normal(0.0005, 0.01, 1000)
a = 1.3 * mkt + rng.normal(0, 0.012, 1000)
print(round(sharpe(0.0005, 0.01), 4))    # → 0.7937
print(round(beta_alpha(a, mkt)[0], 3))   # → 1.374 (true 1.3)
print(round(capm(1.3, 0.05, 0.126), 4))  # → 0.1488
sr = sharpe(mkt.mean(), mkt.std(ddof=1))
print(round(sr, 2))       # → 0.03, though the true value is 0.79

Time O(n) · Space O(n) for n days: one pass for the means, one for the sums of products. The same slope comes out of np.polyfit(mkt, a, 1) (checked: 1.37389).

How they differ from related ideas

✗ Rank by raw return

Ignores risk. With rf = 0, lever a Sharpe-0.79 strategy 2× and its mean doubles to 25.2%, but its sd doubles too, so the Sharpe stays 0.79: nothing was gained per unit of risk.

✗ Rank by volatility

Ignores reward. Stock B (sd 11.8% a year in the simulation) looks safer than A (28.9%), but that says nothing about whether it pays enough for the risk.

✗ Correlation as "market exposure"

Correlation has no scale. β = ρ · σi / σm: a stock with ρ = 0.74 and twice the market's sd has β ≈ 1.5, one with the same ρ and half the sd has β ≈ 0.37.

✓ Sharpe for the whole portfolio, beta for one holding

Sharpe prices total risk and is the right score for what you actually hold. Beta prices only the risk that survives diversification, which is why CAPM uses it for single stocks.

Can you trust a Sharpe or a CAPM number?

Less than it looks. The market in the code has a true Sharpe of 0.79, yet its 1,000-day sample Sharpe came out 0.03. The standard error is about √((1 + SR²/2) / n) per period (Lo 2002), which is 0.50 annualized here: four years of data can't tell 0.3 from 1.3. The √252 scaling also assumes days are independent; autocorrelated returns (smoothed, illiquid assets) overstate it. And Sharpe treats upside and downside wobble alike, so option-selling strategies with rare large losses can post high Sharpes until the loss arrives: people add the Sortino ratio, drawdowns or tail measures.

CAPM is the textbook model, not the working one. Fama and French (2004) summarize decades of tests: the line relating average return to beta is too flat, and size and value explain returns that beta misses. Practitioners use multi-factor models (Fama–French, momentum) for expected returns and still quote beta for market exposure and hedging.
