Markov chains and martingales

Also called absorbing chains, random walks, gambler's ruin and optional stopping. The source guide reaches this only through its craps problem and the "Markov thief"; this card adds the theory behind both, with the interview staple: a fair walk from 3 that stops at 0 or 10.

Prime · 2 minutes before you read

The problem: When many states feed each other, the first-step equations become a system that is slow to solve by hand, and intuition ('it's a fair game, so 50/50') gets the answer badly wrong.

Where it fits: The last conditioning card. First-step analysis gave one equation per state; here the equations become a matrix, (I − Q)⁻¹, and martingales with optional stopping collapse the whole system into one line. cs-10's random walks pick this up.

In one breath

A Markov chain is a process whose next step depends only on where it is now, so a table of "from here, go there with probability p" describes it completely. Questions like "where does it end up?" and "how long does it take?" become a set of linear equations, one per state. A martingale is a running total whose expected next value equals its current value. If you stop it at a sensible time, its expected value when stopped is still the starting value, and that one fact often solves those equations in a single line.

The words, two examples each

Think of a board game with no memory: your next move depends only on the square you're on, never on how you got there.

The martingale shortcut

A fair game can't be beaten in expectation by choosing when to stop, as long as the stopping rule is tame (the box at the end says what that means). Apply that to two martingales and both answers drop out:

E[ST]=S0money is a martingale ⇒ 10h+0(1−h)=3 ⇒ h=0.3P(reach 10) E[ST2−T]=S02spread grows 1 per step ⇒ 100×0.3−E[T]=9 ⇒ E[T]=21= 3 × 7 E[rST]=r3unfair: r = q/p ⇒ h=1−r31−r10ruin formula

A 1-point edge barely matters over 10 dollars (0.300 → 0.259) and crushes you over 100 (0.30 → 0.043): the drift −0.02 per bet adds up over ~1,300 bets, while the noise grows only like √n.

In Python

from fractions import Fraction as F

def ruin(N, p, start):
    """Walk on 0..N, up w.p. p. Returns P(hit N), E[steps]."""
    q = 1 - p
    ids = range(1, N)                     # transient states 1..N-1
    A = [[F(int(i == j)) - (p if j == i + 1 else 0)
          - (q if j == i - 1 else 0) for j in ids] for i in ids]
    hit = solve(A, [p if i == N - 1 else F(0) for i in ids])
    steps = solve(A, [F(1)] * (N - 1))    # (I - Q) t = 1
    return hit[start - 1], steps[start - 1]

def ruin_formula(N, p, i):
    """Closed forms from optional stopping on a martingale."""
    if p == F(1, 2):                      # S_n and S_n^2 - n
        return F(i, N), F(i * (N - i))
    r = (1 - p) / p                       # r**S_n is a martingale
    h = (1 - r**i) / (1 - r**N)
    return h, (i - N * h) / (1 - 2 * p)   # S_n - (2p - 1) n

# solve() is Gauss-Jordan on Fractions; see code/ for it + simulate()
for p in (F(1, 2), F(49, 100)):
    assert ruin(10, p, 3) == ruin_formula(10, p, 3)  # exact match
# → (the __main__ demo in code/ prints)
#   thief: 3 visits x 6 h = 18 h
#   p=0.50 P(10 before 0)=0.3000 E[steps]=21.00  sim 0.3014 20.94
#   p=0.49 P(10 before 0)=0.2592 E[steps]=20.39  sim 0.2603 20.37
#   p=0.49, 30 -> 100: P(win)=0.0433 E[steps]=1284

Time O(n³) · Space O(n²) for n transient states with dense Gauss-Jordan; a walk's matrix is tridiagonal, so a banded solve does it in O(n), and the martingale formula in O(1). The linear system works for any chain; the formula only for this walk.

Why it beats the alternatives

✗ Just simulate

10⁵ walks give 0.3014 ± 0.0015: two or three digits, never an exact 3/10. Each extra digit costs 100× the walks.

✗ Add up every path

A walk can bounce between 1 and 9 for any number of steps, so there are infinitely many paths to 10. You'd be summing an infinite series by hand.

✗ "Fair game, so 50/50"

Fair means your expected money stays $3, not that winning is a coin flip. To keep the average at 3 with endpoints 0 and 10, you must win only 30% of the time.

✓ Equations, then a martingale

One equation per state always works and gives exact answers. When you can spot a martingale, optional stopping turns the whole system into one line: 3/10 and 21.

Does optional stopping always work?

No. It needs the stopping to be tame: T bounded, or E[T] finite with bets of bounded size, or the stopped total bounded (here Sn stays in 0…10). Drop the $10 target and a fair walk from 3 still goes broke with probability 1, yet E[ST] = 0 ≠ 3. That's allowed only because E[T] is then infinite. The doubling strategy (double the bet after each loss) fails the same way: it "surely" wins $1 only with unbounded stakes and an unbounded bankroll.

The Markov step is an assumption too. If the future depends on history, as it does when cards are dealt without replacement, the state has to carry that history (the remaining deck), and the chain gets big. Then use the linear system or dynamic programming over states, not a formula. For the craps problem in the source, the "point" is the state: see first-step analysis.

Understand and remember

  • The next step depends only on the current state → a transition matrix P → hitting probabilities and times solve (I − Q)h = R·1 and (I − Q)t = 1 → the fundamental matrix N = (I − Q)⁻¹ counts expected visits
  • A martingale (a fair game) plus a tame stopping time → E[ST] = S0 → 10h = 3 → h = 0.3; with Sn² − n: 100 × 0.3 − E[T] = 9 → E[T] = 21
  • Unfair bets → Sn drifts, so use rSn with r = q/p → h = (1 − r³)/(1 − r¹⁰) = 0.2592 → over ~1,300 bets (30 → 100) the −0.02 drift per bet swamps the √n noise → 0.043
  • Optional stopping needs T bounded, or a finite E[T] with bounded steps, or a bounded stopped value → with no $10 target, E[ST] = 0 ≠ 3 because E[T] = ∞ → doubling strategies 'win' only with unbounded stakes
  • detail that matters Dense Gauss–Jordan is O(n³), but a walk's matrix is tridiagonal → a banded solve is O(n) → the martingale formula is O(1), but only for this particular walk
