Uniform distributions

Also called the flat or rectangular distribution: a fair die (discrete) or random.uniform(a, b) (continuous). The source guide's discrete Uniform heading is empty; its continuous one has a single problem, real roots of a quadratic with a random coefficient, and its answer there is wrong.

In one breath

Every outcome in the range is equally likely. Discrete: each of n values has chance 1/n, so a probability is a count ÷ n. Continuous: the density is a flat 1/(b − a), so a probability is a length ÷ (b − a). Each single point then has probability 0.

Worked example: the source's problem

"Y is uniform on (0, 5). What is the probability that both roots of 4x² + 4xY + Y + 2 = 0 are real?" Real roots need the discriminant ≥ 0; the plot shows it for every Y in the range.

Drawn to scale from D(Y) at 51 points. The whole axis is the support (0, 5), with density 1/5, so each band's probability is its length ÷ 5.

The source keeps the interval between the roots, (0, 2), and answers 2/5; that is where the discriminant is negative, so 2/5 is the chance of complex roots. Corrected here to 3/5.

Check: Y = 3 gives 4x² + 12x + 5 = 0 with real roots −0.5 and −2.5; Y = 1 gives −0.5 ± 0.707i; Y = 2 gives the double root −1. A simulation of 10⁶ draws (seed 0) gives 0.5995, within one standard error (±0.0005) of 0.6.

In Python

import random
from fractions import Fraction as F

def discrete_uniform(n):
    """Mean and variance of X uniform on {1, ..., n}, by summation."""
    xs = range(1, n + 1)
    mean = F(sum(xs), n)
    var = F(sum(x * x for x in xs), n) - mean**2
    return mean, var          # = (n + 1)/2, (n*n - 1)/12

def disc(y):
    """Discriminant of 4x^2 + 4yx + (y + 2)."""
    return (4 * y) ** 2 - 4 * 4 * (y + 2)   # = 16 (y - 2)(y + 1)

def p_real_roots(a=0, b=5):
    # 16(y - 2)(y + 1) >= 0 outside the roots: y <= -1 or y >= 2
    good = max(0, b - max(a, 2)) + max(0, min(b, -1) - a)
    return F(good, b - a)

def simulate(trials=10**6, seed=0):
    rng = random.Random(seed)
    hits = sum(disc(rng.uniform(0, 5)) >= 0 for _ in range(trials))
    return hits / trials

print(discrete_uniform(6), [disc(y) for y in (1, 2, 3)])
# → (Fraction(7, 2), Fraction(35, 12)) [-32, 0, 64]
print(p_real_roots(), f"{simulate():.4f}")   # → 3/5 0.5995

Exact answers come from Fraction; the simulation only confirms them. The saved file also prints the 1..10 and U(0, 5) strips.

Why it beats the alternatives

Four ways to answer the roots question.

✗ Take the interval between the roots

The source's route: (0, 2) gives 2/5. Between the roots an upward parabola is negative, so that's the complex-roots event. One test point (Y = 1, D = −32) would have caught it.

✗ Count whole-number Y

Treat Y as 1, 2, 3, 4 and count: 3 of 4 give D ≥ 0, so 3/4. But Y is continuous; with values 0..5 the count gives 4/6 instead. Counting only works for a discrete uniform.

✗ Only simulate

10⁶ draws give 0.5995 ± 0.0005: close but never exact. Good as a check, but it can't show that the answer is 3/5.

✓ Sign chart, then length ÷ width

Factor, pick the side of the roots where the inequality holds, test one point, intersect with the support. Exact 3/5 in four lines, and it works for any a, b.

Is "uniform" always the right model?

Only when equal-length pieces really are equally likely, and that stops being true once you transform the variable. If Y ~ U(0, 5), then Y² is not uniform on (0, 25): P(Y² < 12.5) = √12.5 / 5 ≈ 0.707, not 0.5. So choose which variable you call uniform on purpose. "Pick a random point" and "pick a random radius" give different answers.

In code, random.randint(a, b) includes both ends (n = b − a + 1), while randrange(a, b) and random.random() leave the top out. r % n is only uniform when n divides the generator's range: 8 raw values mod 6 give 0 and 1 a 2/8 chance but 2–5 only 1/8 each (illustrative 3-bit generator). Python's randrange uses rejection to avoid this. For a non-uniform target, use a uniform draw with an inverse CDF, or the alias method for a discrete table.
