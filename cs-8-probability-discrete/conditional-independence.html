Conditional independence

Written E1 ⫫ E2 | G, or "independent given G"; the assumption behind naive Bayes and every "each trial is independent" likelihood. The source guide sets up a 3-judge panel (70% of defendants guilty; each judge votes guilty with probability 0.7 if guilty, 0.2 if innocent) and asks three questions without solving them.

Prime · 2 minutes before you read

The problem: Real events are often linked only through a hidden cause, such as the defendant's actual guilt. Treat them as independent and you miss that one guilty vote is evidence; treat them as fully dependent and you need a table of every vote pattern.

Where it fits: The second conditioning card, straight after the Bayes table: it Bayes-updates the hidden cause and then mixes. The same 'independent given the parameter' assumption sits under every binomial likelihood later in the course.

In one breath

Two events can be independent once you know some hidden fact, yet linked when you don't. Judges vote independently given the truth, but a guilty vote from judge 1 is evidence the defendant is guilty, which makes judge 2's guilty vote more likely. The shared hidden cause is what ties them together.

The two rules

Ekjudge k votes guiltyk = 1, 2, 3 G, Idefendant is in fact guilty / innocent (the hidden cause)0.7 / 0.3 gP(Ek | G), a judge's guilty rate for a guilty defendant0.7 iP(Ek | I), the same for an innocent one0.2
joint = 0.7 * 0.7**2 + 0.3 * 0.2**2 = 0.343 + 0.012 = 0.3550 split = (0.7 * 0.7 + 0.3 * 0.2)**2 = 0.55**2 = 0.3025

The two agree only if g = i, that is, when the truth doesn't change how judges vote. Otherwise the average of squares beats the square of the average, so the votes are positively linked: P(E2 | E1) = 0.355 / 0.55 = 0.6455, up from 0.55.

The source's three questions: P(judge 3 votes guilty | judges 1 and 2)

Condition on the hidden cause: update P(G) from the first two votes (a Bayes step), then judge 3 votes guilty at 0.7 or 0.2 in that updated mix. Given G, judge 3 ignores the other two.

P(E3 | votes) = P(G | votes) * 0.7 + P(I | votes) * 0.2

Row a filled in: 0.9662 × 0.7 + 0.0338 × 0.2 = 0.6831. Every answer sits between 0.2 and 0.7, pulled toward whichever world the first two votes favour. A simulation of 10⁶ trials (seed 0) gives 0.6822, 0.5745 and 0.3224, within 3 standard errors (about ±0.0008 each).

The source's last question: E1, E2, E3 are not independent (0.355 ≠ 0.3025), but they are conditionally independent given G (0.49 = 0.7²) and given I (0.04 = 0.2²), because the problem says each judge votes independently once the truth is fixed.

In Python

from fractions import Fraction as F

PRIOR = {"G": F(7, 10), "I": F(3, 10)}   # guilty / innocent
VOTE = {"G": F(7, 10), "I": F(2, 10)}    # P(one guilty vote | truth)

def p_votes(votes, truth):
    """P(vote pattern | truth): a product, by cond. independence."""
    q = VOTE[truth]
    out = F(1)
    for v in votes:
        out *= q if v else 1 - q
    return out

def p(votes):
    """Unconditional P(votes): mix the two truths by their priors."""
    return sum(PRIOR[t] * p_votes(votes, t) for t in PRIOR)

def p_judge3(votes12):
    """P(E3 | judges 1 and 2 voted votes12)."""
    return p(votes12 + (1,)) / p(votes12)

Time O(n · t) · Space O(1) for n votes and t hidden worlds: the product inside each world is what conditional independence buys; without it you'd need a table of all 2n vote patterns per world. The simulation is in code/conditional-independence.py.

Think of two thermometers in the same room: their readings move together, but only because they both track the room's temperature. Fix the temperature and one tells you nothing about the other.

Why conditioning on the cause beats the alternatives

✗ Treat the votes as independent

Then P(E3 | both guilty) = P(E3) = 0.55. The real answer is 0.6831: off by 0.13, because two guilty votes are strong evidence of guilt.

✗ Assume the votes reveal the truth

"Both said not guilty, so innocent, so 0.2." But P(G | both not) is still 0.2471, and the answer is 0.3235. It fails worst when the votes are weak evidence.

✗ Enumerate every outcome

Correct: 2 worlds × 2³ vote patterns = 16 rows. But 12 jurors need 8,192 rows, and the table hides why the answer moves.

✓ Condition on the hidden cause

Update P(G) from the votes you saw, then mix 0.7 and 0.2 by it. Two lines per question, and it scales to any number of judges because each world is a simple product.

Is conditional independence something you can count on?

No: it's an assumption, and the problem hands it to you. Real judges deliberate and read the same evidence, so their votes stay correlated even given the truth; naive Bayes spam filters make the same assumption about words, and correlated words then count the same evidence twice, pushing the probabilities too far toward 0 or 1 (our inference). When it fails, you need the joint distribution of the votes given G, or a richer hidden variable (such as "strength of the evidence") that the votes are independent given.

Neither direction implies the other. Dependent votes became independent given G here, and independent coins became dependent given "at least one head". Always say which variable you're conditioning on.

Understand and remember

  • Votes depend on a hidden cause G → given G, each vote is an independent coin (0.7 or 0.2) → without G, a guilty vote raises P(G) → which raises the next vote's chance: P(E2 | E1) = 0.6455, up from 0.55
  • P(E1E2) is an average of squares and P(E1)P(E2) is the square of an average → they are equal only if g = i → otherwise agreeing votes are over-represented (0.355 against 0.3025)
  • To predict a new vote → Bayes-update P(G | earlier votes) → mix 0.7 and 0.2 by it → 97/142, 15/26, 11/34
  • Conditional independence makes P(votes | world) a product → n votes cost O(n·t) instead of a table of 2n patterns per world → 12 jurors need 24 factors instead of 8,192 rows
  • detail that matters The assumption is handed to you by the problem → real judges share evidence and naive-Bayes words repeat → correlated clues get counted twice → the probabilities are pushed too far toward 0 or 1

5 · Predict commit to an answer before revealing

Twelve judges have all voted guilty. What is P(the thirteenth votes guilty), and what number does it approach as the unanimous votes pile up? Commit first.

Reveal

About 0.7000 (0.69999994). Each guilty vote multiplies the odds of guilt by 0.7/0.2 = 3.5, so P(G | 12 guilty) ≈ 0.99999987, and the mix is almost pure 0.7. The limit is 0.7, not 1: even certain guilt only gives the judge's own rate. Compare 0.6455 after one vote, 0.6831 after two and 0.6951 after three.
