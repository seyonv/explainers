Checkpoint 2: split on the unknown

Ties together Bayes as a table, conditional independence, convolution, first-step analysis and Markov chains and martingales: five ways to condition on the one thing you don't know, answer each case where it's easy, and weight the cases by how likely they are.

How to use this page. Close the five cards. Answer each question in writing, in full sentences, before opening its Check. A wrong or shaky answer isn't a failure: it tells you exactly which section to reopen. The questions are mixed on purpose, so you first have to work out which idea applies.

1 · Mixed retrieval

  1. which concept?A condition has prevalence 1%. A test detects it with probability 0.9 and gives a false positive with probability 0.05. A patient tests positive twice, and the two tests are independent given the patient's true status. What is P(condition)? Which two ideas does the answer combine?
    Check
    • a Bayes table with two rows, condition and healthy; the prior is 0.01 against 0.99
    • independence given status lets you multiply the likelihoods: 0.9² = 0.81 against 0.05² = 0.0025
    • posterior = 0.0081/(0.0081 + 0.002475) = 36/47 ≈ 0.766; one positive alone gives only 2/13 ≈ 0.154

    Missed it? Reopen Bayes as a table, the odds form, and conditional independence, "The two rules".

  2. Each week's claim count N has P(N = n) = 1/2n+1, and weeks are independent. Two weeks brought 7 claims in total. What is P(the first week had none)?
    Check
    • the convolution's cases are the 8 splits 0 + 7, …, 7 + 0, each with joint probability 1/512
    • conditioning on the total leaves them equally likely: (1/512)/(1/64) = 1/8
    • that is Bayes applied to the convolution's cases

    Missed it? Reopen convolution, the hand trace.

  3. which concept?What is the expected number of rolls of a fair die until you see two 6s in a row?
    Check
    • first-step analysis with two states: E0 (no 6 last roll) and E1 (a 6 last roll)
    • E0 = 1 + (1/6)E1 + (5/6)E0 and E1 = 1 + (5/6)E0
    • the first gives E0 = 6 + E1; substituting gives E0/6 = 7, so E0 = 42

    Missed it? Reopen first-step analysis, "The method", and Markov chains for states that feed each other.

  4. Why is P(judge 2 votes guilty | judge 1 voted guilty) = 0.6455 and not 0.55, when the judges vote independently?
    Check
    • they vote independently given the truth, not unconditionally
    • judge 1's guilty vote raises P(guilty) from 0.7 to 0.49/0.55 ≈ 0.891
    • mixing 0.7 and 0.2 by the updated belief gives 0.355/0.55 = 0.6455

    Missed it? Reopen conditional independence, the worked example.

  5. A fair $1 game on 0…5, starting at $2, stopping at $0 or $5. Give P(reach $5) and the expected number of bets, and name the tool that gets each in one line.
    Check
    • Sn is a martingale and T is tame (the walk stays in 0…5): 5h = 2, so h = 2/5
    • Sn² − n is a martingale: 25 × 2/5 − E[T] = 4, so E[T] = 6 = 2 × 3
    • the linear system gives the same answers; the martingale is the shortcut

    Missed it? Reopen Markov chains and martingales, "The martingale shortcut".

  6. which concept?A gambler plays a fair game with no floor, and stops the first time he is $1 ahead. He will stop ahead with probability 1. Why doesn't that contradict "a fair game can't be beaten by choosing when to stop"?
    Check
    • optional stopping needs a tame stopping time: bounded, or a finite E[T] with bounded steps, or a bounded stopped value
    • with no floor, E[T] is infinite and the losses along the way are unbounded
    • so E[ST] = S0 + 1 doesn't contradict the theorem; its conditions fail (the same flaw as the doubling strategy)

    Missed it? Reopen Markov chains and martingales, "Does optional stopping always work?".

  7. In the car-year problem, someone forgets the "other" row. What answer do they get for P(1997 | accident), and why is it wrong?
    Check
    • 0.0080/(0.0080 + 0.0036 + 0.0060) = 0.0080/0.0176 ≈ 0.455, against the correct 2/9 ≈ 0.222
    • the rows must not overlap and must cover every case; dropping one shrinks P(E)
    • here the dropped row was the biggest joint, 0.0184

    Missed it? Reopen Bayes as a table, "Plugging into the formula".

  8. In craps, the point is 5. What is P(win), and why do all the other rolls drop out?
    Check
    • w = 4/36 + (26/36)w, since a 5 wins, a 7 loses and the other 26/36 of rolls return to the same state
    • w = P(5)/(P(5) + P(7)) = 4/10 = 2/5
    • the process has no memory, so a neutral roll leaves the value unchanged

    Missed it? Reopen first-step analysis, worked example 1.

3 · Project: triage a failing test

What it reinforces: a Bayes update over a hidden state (Bayes as a table), runs that are independent given that state (conditional independence), first-step equations with two states (first-step analysis, Markov chains), and the distribution of a total (convolution).

A CI test is either broken (prior 0.2; each run fails with probability 0.9) or flaky (prior 0.8; each run fails with probability 0.1). Given which it is, runs are independent. The model is made up for this checkpoint. In about 30 lines of Python with Fractions:

  1. One run. P(a run fails), before you know which kind of test it is.
  2. Update. The test failed twice. P(broken)? Then predict P(the third run fails).
  3. A tie. The test failed once and then passed once. P(broken)? Explain the answer from the likelihood ratio, without computing the table.
  4. Reruns. For a random test (kind unknown), what is the expected number of runs until its first pass? Condition on the kind first.
  5. Two passes in a row. A known-flaky test is rerun until it passes twice in a row. Write the first-step equations for the states "last run failed or no runs yet" and "last run passed", and solve for the expected number of runs.
  6. A total. One known-broken test and one known-flaky test each run twice. Get the pmf of the total number of failures by convolving the two binomials.
  7. Check. Simulate 10⁵ tests with a fixed seed and confirm steps 2 and 5 to within a few standard errors.
Done when: every step has an exact Fraction, your simulation agrees with steps 2 and 5, and you can say in one sentence why step 3 returns exactly the prior. Then compare with the check.
Check: the numbers (exact, from Fractions)
  • Step 1: 0.2 × 0.9 + 0.8 × 0.1 = 13/50 = 0.26.
  • Step 2: 0.2 × 0.81 / (0.162 + 0.8 × 0.01) = 81/85 ≈ 0.9529; the next run fails with probability 0.9529 × 0.9 + 0.0471 × 0.1 = 733/850 ≈ 0.8624.
  • Step 3: 1/5, exactly the prior. Fail-then-pass has likelihood 0.9 × 0.1 = 0.09 under both kinds, so the likelihood ratio is 1 and the evidence cancels.
  • Step 4: runs to the first pass are geometric given the kind, with means 1/0.1 = 10 (broken) and 1/0.9 = 10/9 (flaky). Mixed: 0.2 × 10 + 0.8 × 10/9 = 26/9 ≈ 2.89.
  • Step 5: E0 = 1 + 0.9E1 + 0.1E0 and E1 = 1 + 0.1E0, so E0 = 190/81 ≈ 2.35 runs (and E1 = 100/81).
  • Step 6: the broken test's failures are 0, 1, 2 with probability 0.01, 0.18, 0.81; the flaky test's 0.81, 0.18, 0.01. Convolving gives totals 0…4 with probability 0.0081, 0.1476, 0.6886, 0.1476, 0.0081.
