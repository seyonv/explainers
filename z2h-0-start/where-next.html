In one breath: this series stops at a pretrained GPT-2. To go further, nanochat takes the same ideas through the whole chat-model pipeline, and llm.c rewrites the GPT-2 training in raw C/CUDA. Karpathy's planned course, LLM101n, still doesn't exist. His two long talks explain the modern LLM stack without building it.

Predict first: after z2h-10 you have a model that continues text. What's still missing before you can chat with it, and which of the projects below covers that?

Finetuning on conversations, and a chat interface to talk to it through. A pretrained model only continues documents. nanochat's pipeline adds supervised finetuning (chat_sft.py), reinforcement learning (chat_rl.py) and a chat CLI on top of the same kind of GPT you built.

Which one first?

Want a chat model you trained

nanochat. Run runcpu.sh on the M3 first to learn the pipeline, then rent a node for the real speedrun.

Want to know what PyTorch hides

llm.c. It's the z2h-6 idea (write every backward pass yourself) applied to the whole of GPT-2, in C and CUDA.

Want the big picture

The Deep Dive talk. It places everything you built into the full pipeline, including the parts after pretraining.

✓ Not sure

nanochat. It reuses the most of what you built (a GPT, a BPE tokenizer, the training loop) and adds the steps this series leaves out.

Understand and remember

  • A pretrained model only continues documents → a chat model needs finetuning on conversations plus RL → nanochat adds exactly those stages on top of a GPT like yours
  • PyTorch hides the kernels and every backward pass → llm.c writes them by hand in C/CUDA → the z2h-6 idea applied to all of GPT-2 → you learn what the framework does for you, at the cost of much more code
  • Costs quoted by a project (README: $48 for ~2 h of 8×H100; llm.c #481: $20 for 90 min) → they depend on the hourly price → check your provider's rate before renting
  • detail that matters nanoGPT's README now calls it deprecated and points to nanochat → build-nanogpt (z2h-10) is still the right teaching path, but for new work you'd start from nanochat

5 · Predict commit to an answer before revealing

nanochat's leaderboard went from 3.04 h (Jan 2026) to 1.65 h (Mar 2026) to reach GPT-2 grade on the same 8×H100 node. Commit first: at roughly $24/h for the node (the README's figure), about how much did one run's cost fall?

Reveal

From about 3.04 × 24 ≈ $73 to about 1.65 × 24 ≈ $40, a saving of about $33 per run, or about 46%. Same hardware and price, so the cost falls in direct proportion to the time.
