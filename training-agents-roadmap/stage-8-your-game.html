Checkpoint

Closed book. Write your answer before you open each one. If you miss one, reread the block it names, not the whole stage.

  1. The observation shows the dials and the target, but never the wiring. What feedback must the game still never give, and why?

    Answer

    Anything that makes a trivial policy optimal, like the number of moves left on the best route or a “warmer/colder after this move” hint. Then following the hint beats probing, just as the GeoGuessr pin tool never reports distance.

    Reread: What makes a game a good RL environment (Stage 3)

  2. Tabular Q-learning reached 100% on fresh safes. Why isn't that the end of the story?

    Answer

    It only holds for the one wiring it trained on (the difference state makes it generalise across targets, not wirings). A new wiring needs a new table; an LLM policy has to read the wiring and generalise.

    Reread: The game: Safecracker (Stage 0)

  3. Your 5-step smoke test shows frac_reward_zero_std = 0.9. What do you do?

    Answer

    Nine in ten groups teach nothing. Make the task easier for this model (shorter optimal paths, fewer links, bigger budget), switch to a graded reward, or use more generations per prompt.

    Reread: Stage 3's move

  4. Train reward is flat but the held-out eval curve rises. Believe it?

    Answer

    Yes, if the eval set is fixed and disjoint: per-step training reward mixes in which safes were drawn (large noise), while a fixed set removes it. That's exactly what Class 4 saw.

    Reread: Stage 6's move
