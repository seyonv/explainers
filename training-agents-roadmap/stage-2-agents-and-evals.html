  1. The agent loop and what a trace is

    ~2.5 h

You need this because your frontier sweep is an agent loop: one move per message, and the transcript is the trace you'll grade.

An agent is a loop. The model reads the conversation so far and either answers or asks to call a tool (run bash, edit a file). The harness runs the tool, appends the output as a new message, and calls the model again, until the model stops or a step or cost budget runs out.

The full record of one run (system prompt, task, every assistant turn with its tool calls, every tool result) is a trajectory or trace. A trace dataset is many of these, stored as messages lists. Class 1 trains on 627 real sessions from Mario Zechner's Pi harness (badlogicgames/pi-mono), so it's worth opening one now.

  1. pass@k, repeats and error bars

    ~1.5 h

You need this because “beats frontier models” only means something with an interval around both numbers.

An agent eval puts the agent in a fresh sandbox with a task and grades the end state, usually with hidden tests. The score is noisy three ways: the model samples differently each run, tasks vary in difficulty, and even the infrastructure adds noise. So you repeat tasks, report pass@1 with an error bar, and worry about contamination (the model saw the benchmark in training).

pass@k is the chance that at least one of k attempts passes. From n = 10 attempts with c = 3 correct: pass@1 = 3/10 = 0.30, and pass@5 = 1 − C(7,5)/C(10,5) = 1 − 21/252 = 0.917. The error bar on a pass rate p over N tasks is about ±1.96·√(p(1−p)/N): at 40% on 50 tasks that's ±13.6 points, so 40% vs 45% is not a result yet.

  2. Agent X gets 40% and agent Y 45% on 50 tasks. What do you say?

    Answer

    The 95% error bar is about ±13.6 points at that size, so the intervals overlap heavily: not a real difference yet. Run more tasks or repeats.

    Reread: pass@k, repeats and error bars

  3. Which messages in a trace should a model be trained to write, and which not?

    Answer

    Train on the assistant turns (its reasoning and tool calls). Mask the system prompt, the user's task and the tool outputs: the world wrote those.

    Reread: The agent loop and what a trace is

  4. Give two reasons from the workshop that a leaderboard number overstates real usefulness.

    Answer

    Any two of: omitted tasks and missing error bars (Avijit); accuracy rising faster than reliability across runs (Arvind); harness effects, where the same model scores differently in different scaffolds (Mahesh); contamination; graders the agent can read or game.
