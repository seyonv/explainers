Build an LLM study path · Day 2 · one page

Text → batches, then attention

Day 2 of the Build an LLM path: Raschka chapters 2 and 3. Turn raw text into training batches, then code attention from a version without weights up to multi-head causal attention. You've seen both on the LLM basics path; today you write them. Everything is inline: just scroll. Ticks are shared with the checklist version.

What today uses, and why

Day 1 of LLM basics took text to vectors and Day 2 explained attention. Today you code both, plus the part the basics path skipped: how a text becomes training batches.

Raschka chapters 2 and 3Data and attention.

Training pairs cardWritten for this path.
The one idea chapter 2 moves through quickly, measured on a real model.
Zero to Hero course 9 (optional)Train a tokenizer.
The book uses tiktoken; this is the way to see one being built.
By the end of today, you'll be able to
  • Build a data loader that turns a text into (input, target) batches with a sliding window, and explain context length and stride.
  • Explain why one forward pass on n tokens gives n training examples.
  • Code self-attention, a causal mask and multi-head attention, and give the shape of every tensor.
How to use this page
  1. Scroll. The bar pinned at the top always says what the current step is and how to read it: Read Skim Revisit Checkpoint Build Task.
  2. Each phase opens with a Before you read box: the questions to read with, and a link to try the phase's checkpoint cold.
  3. The first step of each phase is a card from this hub, shown inline with its Prime and Study boxes. Most readings after it are outside pages that open in a new tab. A few load inline.
  4. Tick Done as you finish a step. Take a break after each checkpoint.
  5. Checkpoint answers stay closed until you open them. Each one says which source to reopen if you missed it.
