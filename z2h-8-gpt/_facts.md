# Shared facts: Let's build GPT (z2h-8-gpt)

Every card writer reads this file before writing. Reuse these values exactly.

## This course
Lecture 7 of Zero to Hero: build a character-level Transformer on tiny Shakespeare, following 'Attention Is All You Need' and GPT-2/3. Self-attention, multi-head attention, feed-forward, residuals, LayerNorm and dropout get added one at a time, and validation loss goes from 4.87 to 1.48.
- Lecture: L7. 17 concept cards plus `big-ideas.html` and `_overview.html` (written after the concept cards).
- **Running example / conventions for this course:** tiny shakespeare (1,115,394 characters, vocab 65, 90/10 split); gpt.py hyperparameters batch 64, block 256, n_embd 384, 6 heads, 6 layers, dropout 0.2, lr 3e-4, 5000 iters; 10,788,929 params; per-step val losses (map-C table: 4.87 untrained, ~2.5 bigram, 2.4, 2.28, 2.24, 2.08, 2.06, 1.48); your M3 runs gpt.py at ~1.2 s/step (see _facts local measurements).

### Colour meanings (flat style, same on every card)
- green `--accent`: the correct answer, what's learned/kept, the winner, the current step
- grey `--faint` / `--surface2`: discarded, masked, saturated/dead, overhead
- neutral `--text` / `--muted`: data at rest
- red `--red`: ✗, a bug, a loss that's too high, a cutoff, the worst value
- Gradients are always written `.grad` / `d<name>` in text; in sketches, blue ink.
