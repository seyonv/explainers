Checkpoint 1: windows and stacks

Ties together sliding window with counts, the monotonic deque, queues as rolling state, stacks for parsing and the monotonic stack: five one-pass techniques where each item enters once and leaves once, and what each one keeps about the items it has seen.

How to use this page. Close the five cards. Answer each question in writing, in full sentences, before opening its Check. A wrong or shaky answer isn't a failure; it tells you exactly which section to reopen. The questions are mixed on purpose, so you have to work out which idea applies before you can answer.

1 · Mixed retrieval

  1. which concept?A weather service stores 365 daily highs and must report, for every day, the hottest of the last 7 days. Which technique fits, how many comparisons would rescanning each window cost, and what bounds the better method's work?
    Check
    • a fixed-width window that only needs its maximum: the monotonic deque
    • rescanning: (n − k + 1)(k − 1) = 359 × 6 = 2,154 comparisons
    • deque: each index is pushed once and popped at most once, so at most 2n = 730 operations, whatever k is

    Missed it? Reopen the monotonic deque, "Why it beats the alternatives".

  2. In Minimum Window Substring with s = "ADOBECODEBANC" and t = "ABC", the window [1, 10) reads DOBECODEB. When the second B is added, why does missing stay at 1, and what finally makes the window valid again?
    Check
    • need[B] was already 0 (the first B paid the debt), so the second B only makes it −1: a spare
    • missing counts positive debts only, and A is still owed: missing stays 1
    • the A at index 10 pays it: missing becomes 0 and the shrink loop starts

    Missed it? Reopen sliding window with counts, "The four moving parts".

  3. which concept?A referral program: each new user brings in one new user per day, starting 2 days after joining, and churns 4 days after joining. You need the number of active users on day n for n up to 10⁶, with memory that doesn't grow with n. Which technique, what does it store, and what is day 6's answer if one user joins on day 1?
    Check
    • a recurrence that looks back a bounded number of days: a deque as rolling state
    • store only the last 4 days of newcomers; each day add those who start inviting, subtract those who churn, append today
    • it is exactly People Aware of a Secret with delay 2, forget 4: day 6 gives 5

    Missed it? Reopen queues as rolling state, the recurrence and hand trace.

  4. A code reviewer says your Largest Rectangle solution is O(n²) because a while loop sits inside the for loop. How do you answer, and on which input does the stack grow deepest?
    Check
    • each index is pushed once and popped at most once over the whole pass
    • so all iterations of the inner while together are at most n: O(n) total, amortized O(1) per step
    • deepest on heights sorted ascending: nothing pops until the sentinel, n + 1 entries

    Missed it? Reopen the monotonic stack, the complexity line, and Big-O and amortized O(1).

  5. Run Longest Valid Parentheses on "(()". What is the answer, what is left on the stack at the end, and what does the leftover mean?
    Check
    • push 0 and 1 over the base −1; the ) at 2 pops 1, the top is 0, length 2 − 0 = 2
    • the stack ends as [−1, 0]
    • index 0 is an unmatched ( that acts as a boundary: no valid run can extend past it to the left

    Missed it? Reopen stacks for parsing, worked example 2.

  6. which concept?For each day in a list of temperatures you need the number of days until a warmer one. Which structure, and what does a pop mean at the moment it happens?
    Check
    • nearest greater element to the right: a monotonic stack of indices with non-increasing temperatures
    • a warmer day i pops every cooler index j on top: i is j's first warmer day, so the answer is i − j
    • O(n), and indices never popped get 0

    Missed it? Reopen the monotonic stack, "Is it always the tool?", and compare the deque's pop in the monotonic deque.

  7. Sliding window with counts shrinks from the left while the window is valid. Give one question where that shrink rule is correct and one where it silently misses answers, and say what property separates them.
    Check
    • correct: contains all of t, at most k distinct, sum ≥ target with non-negative numbers
    • fails: subarray sum equals k with negative numbers; use a prefix-sum dictionary
    • the property is monotone validity: growing a valid window keeps it valid, shrinking an invalid one keeps it invalid

    Missed it? Reopen sliding window with counts, "Does every window problem work this way?".

3 · Project: a temperature dashboard in one pass each

What it reinforces: the next-greater pop (monotonic stack), front expiry and back pops (monotonic deque), grow-right / shrink-left under a monotone condition (sliding window with counts), and the each-index-once argument (Big-O and amortized O(1)).

T = [73, 74, 75, 71, 69, 72, 76, 73] # daily highs, the classic example

In about 50 lines of Python:

  1. Days until warmer. For each day, how many days until a strictly warmer one (0 if none)? Use a monotonic stack and count pushes and pops.
  2. Hottest of the last 3 days. For each full window of k = 3, the maximum. Use a monotonic deque and count pushes and pops (expiries included).
  3. Longest calm stretch. The longest run of consecutive days whose max − min ≤ 3. Grow right one day at a time; keep one deque for the max and one for the min; while max − min > 3, move left forward and expire the fronts it passes. Count all deque operations.
  4. Check it. Write the obvious O(n²) or O(n³) version of each and compare on 1,000 random inputs (n from 1 to 12, temperatures 60–80, tolerance 0–5, a seeded generator).
  5. Bound it. For part 3, print the largest ratio (deque operations ÷ n) over those 1,000 inputs and explain the bound it must stay under.
Done when: your three answers match the brute force on all 1,000 inputs, you can say why part 3's shrink is safe (is max − min ≤ d monotone?), and you can state the operation bound for each part. Then compare with the check.
Check: the numbers (computed with a Python version of exactly these steps)
  • Days until warmer: [1, 1, 4, 2, 1, 1, 0, 0], with 8 pushes and 6 pops (14 operations ≤ 2n = 16).
  • Window max, k = 3: [75, 75, 75, 72, 76, 76], also 14 deque operations.
  • Longest calm stretch: 3 days, first found at indices 0–2 (73, 74, 75); 71, 69, 72 also has length 3. Part 3 used 29 deque operations for n = 8.
  • Safe shrink: removing days from a valid stretch can't raise the max or lower the min, so validity is monotone, the same property the counts window needs.
  • Bound: each index enters and leaves each of the two deques at most once, so at most 4n operations. Over 1,000 random inputs (seed 0) the worst ratio was 3.83 per element, and all three parts matched the brute force on every input.
