Checkpoint 1: searching and structuring graphs

Ties together depth-first search and flood fill, breadth-first search in layers, union–find, topological sort, bipartite graphs and Eulerian paths: six ways to visit a graph once, and what each one remembers while it does.

How to use this page. Close the six cards. Answer each question in writing, in full sentences, before opening its Check. A wrong or shaky answer isn't a failure; it tells you exactly which section to reopen. The questions are mixed on purpose, so you have to work out which idea applies before you can answer.

1 · Mixed retrieval

  1. which concept?A game map starts as all water. Land appears one cell at a time, 10⁴ times on a 100 × 100 grid, and after every addition the UI shows the current number of islands. Which structure do you use, and what does the obvious alternative cost?
    Check
    • union–find: each new cell starts its own island, and each union that joins two different roots removes one
    • at most 4 unions per add, each α(n) ≤ 4 amortized with union by size and path compression
    • recounting with a flood fill after every add visits up to 1 + 2 + … + 10,000 = 50,005,000 land cells

    Missed it? Reopen union–find, the island formula and "Why it beats the alternatives".

  2. Five people have the dislikes [[1,2],[2,3],[3,4],[4,5],[5,1]]. Run BFS 2-colouring from person 1. Where does it fail, and how long is the odd cycle it proves?
    Check
    • 1 A; pop 1: 2 B, 5 B; pop 2: 3 A; pop 5: 4 A
    • pop 3: neighbour 4 is also A → conflict on the edge 3–4
    • cycle length d(3) + d(4) − 2·d(1) + 1 = 2 + 2 − 0 + 1 = 5: the whole ring

    Missed it? Reopen bipartite graphs, "Why an odd cycle is the only obstacle".

  3. which concept?A package manager must install packages so that every dependency is installed first, run independent installs in parallel, and refuse when the dependencies loop. Which algorithm gives all three, and how does it notice the loop?
    Check
    • Kahn's topological sort: in-degree = dependencies not yet installed
    • the queue at any moment is exactly the set that can install now, which is the parallel batch
    • a loop's packages never reach in-degree 0, so fewer packages are placed than exist

    Missed it? Reopen topological sort, the Kahn trace and "Is Kahn always the tool?".

  4. The recursive flood fill fails on a 32 × 32 all-land grid, but the explicit-stack version fills a 1000 × 1000 grid. What is different about where each one keeps its pending cells, and why is the recursion depth equal to the cell count here?
    Check
    • recursion keeps one Python frame per cell on the current path; CPython stops near 1,000 frames
    • on an all-land grid the neighbour order snakes through every cell before backing up, so depth = 1,024
    • the explicit stack is an ordinary list on the heap: no depth limit, same O(R·C)

    Missed it? Reopen flood fill, "Why not just recurse?".

  5. which concept?A street-sweeping truck must drive along every one-way street of a district exactly once. Which property decides whether a route exists, and what would change if it had to visit every intersection exactly once instead?
    Check
    • every street once = an Eulerian path: out − in must be 0 everywhere except +1 at the start and −1 at the end, and all streets connected
    • Hierholzer finds it in O(E) after sorting
    • every intersection once = a Hamiltonian path: NP-complete, no degree test decides it

    Missed it? Reopen Eulerian paths, "When a path exists" and the Hamiltonian row.

  6. BFS on the stop ↔ bus graph answers Bus Routes in O(S). Why does BFS's first arrival at the target give the fewest buses, and why are buses modelled as nodes at all?
    Check
    • the FIFO queue holds at most two layer numbers, so every node at distance d is found before any at d + 1
    • a stop links to its buses: one route of L stops costs L links, not L(L − 1) stop-to-stop edges
    • each layer is one more bus; each bus is boarded once, each stop queued once

    Missed it? Reopen BFS in layers, "Why the first arrival is the shortest".

  7. Hierholzer writes a node down when it gets stuck, and reverses the list at the end. Why must the first node it gets stuck on be the end of the itinerary?
    Check
    • every balanced node you enter still has an unused edge out, so you can't be stuck there
    • only the node with one extra in-edge can run out first
    • so it is written first and, after the reversal, comes last; later detours splice in before it

    Missed it? Reopen Eulerian paths, "The case that needs the stack: a dead end".

3 · Project: one graph, five questions

What it reinforces: components (union–find), layers (BFS), two-colouring and its certificate (bipartite), degree conditions and the stack walk (Eulerian paths), and in-degree ordering with cycle detection (topological sort). One small input, every tool run on it, each answer checked against the others.

nodes 0 … 7, undirected edges: (0,1) (0,2) (1,2) (1,3) (2,4) (3,4) (3,5) (4,5) (6,7)

In about 60 lines of Python, using the snippets from the cards:

  1. Components. Run union–find over the edges in the order given. Count the components, and list the edges whose ends already share a root (the ones that close a cycle).
  2. Layers. BFS from node 0 with neighbours in the order the edges list them. Print each layer.
  3. Two colours. Run BFS 2-colouring on every component. Report the first conflict edge and the odd cycle it proves.
  4. Every edge once. Print every node's degree. Can the component {0 … 5} be drawn in one stroke? Add the single edge (1, 4), repeat the degree check, and find the path with Hierholzer (undirected: give edges ids and mark them used from both ends; take the smallest neighbour first).
  5. Order. Orient every edge from the smaller id to the larger and run Kahn's algorithm with a FIFO queue. Then add the directed edge 5 → 0 and run it again.
Done when: all five parts print, you can say why part 1's cycle-closing edges and part 3's conflict agree that the graph has cycles, and you can predict from part 4's degrees where the Euler path must start and end before running it. Then compare with the check.
Check: the numbers (computed with a Python version of exactly these steps)
  • Components: 2 ({0 … 5} and {6, 7}), after 6 successful unions. The edges (1, 2), (3, 4) and (4, 5) find their ends already joined.
  • Layers from 0: [0], [1, 2], [3, 4], [5]. Nodes 6 and 7 are never reached: BFS covers one component.
  • Two colours: 0 A, then 1 B and 2 B, and popping 1 finds 2 also B. Conflict edge 1–2, odd cycle 1-0-2-1 (length 1 + 1 − 0 + 1 = 3). Not bipartite.
  • Degrees: 0 → 2, 1 → 3, 2 → 3, 3 → 3, 4 → 3, 5 → 2, 6 → 1, 7 → 1. Four odd-degree nodes in {0 … 5}, so no one-stroke drawing. With (1, 4) added, nodes 1 and 4 become even and only 2 and 3 are odd: a path from 2 to 3. Hierholzer from 2 gives 2, 0, 1, 2, 4, 1, 3, 4, 5, 3: all 9 edges.
  • Kahn with low → high edges: 0, 6, 1, 7, 2, 3, 4, 5 (every orientation from small to large is acyclic). With 5 → 0 added, only 6 and 7 are placed: 2 of 8, so the cycle 0 → 1 → 3 → 5 → 0 (among others) blocks everything else.

Dijkstra's algorithmAlso called single-source shortest paths, or uniform-cost search when it stops at one target. It finds the cheapest route from one node to every other when no edge weight is negative. The source…In one breathKeep a min-heap of (distance so far, node). Pop the closest unfinished node: nothing still in the heap can beat its distance, because every other route has to leave the heap at a cost at least that big and weights only add. Mark it final, try each out-edge ("relax" it), push any improvement, and repeat.
