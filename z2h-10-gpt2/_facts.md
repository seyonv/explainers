# Shared facts: Reproducing GPT-2 (124M) (z2h-10-gpt2)

Every card writer reads this file before writing. Reuse these values exactly.

## This course
The Zero to Hero playlist's capstone (not listed on the course page): write GPT-2 as a PyTorch module, load OpenAI's weights, then train it from scratch on FineWeb-Edu with every speed trick (TF32, bf16, torch.compile, flash attention, fused AdamW, DDP) until it beats GPT-2 on HellaSwag.
- Lecture: L9. 15 concept cards plus `big-ideas.html` and `_overview.html` (written after the concept cards).
- **Running example / conventions for this course:** GPT-2 124M = 124,475,904 params (12 layers, 12 heads, 768 dims, context 1024, vocab 50257 → padded 50304); init loss ≈ −ln(1/50257) = 10.82; the A100 speed ladder in ms/step (fp32 ~1000 → TF32 333 → bf16 300 → compile 130 → flash ~96 → 50304 93 → fused AdamW 90); 0.5M-token batches; GPT-2 124M HellaSwag 29.4%, GPT-3 124M 33.7%, reproduction 33.24% after 40B tokens (map-D). Your M3: ~1,100–1,350 tokens/s for the 124M model, so full training ≈ 88 days — tag each build step M3 / M3-slow / rented GPU. HellaSwag's GitHub source is DMCA-blocked (HTTP 451, 2026-09-14): use the Hugging Face Rowan/hellaswag copy (labs adapter).

### Colour meanings (flat style, same on every card)
- green `--accent`: the correct answer, what's learned/kept, the winner, the current step
- grey `--faint` / `--surface2`: discarded, masked, saturated/dead, overhead
- neutral `--text` / `--muted`: data at rest
- red `--red`: ✗, a bug, a loss that's too high, a cutoff, the worst value
- Gradients are always written `.grad` / `d<name>` in text; in sketches, blue ink.
