Build an LLM study path · Day 4 · one page

Pretrain it

Day 4 of the Build an LLM path: Raschka chapter 5 and appendix D. Measure how wrong your model is, train it on a small text until it writes recognisable sentences, control how it picks tokens, then load OpenAI's real GPT-2 weights into your own code. Everything is inline: just scroll. Ticks are shared with the checklist version.

What today uses, and why

An untrained model writes gibberish. Today it learns, first from a short story and then from OpenAI's weights.

Raschka chapter 5 and appendix DPretraining.
The training loop, the tricks that keep it stable, decoding and loading GPT-2.
Zero to Hero course 10 (stretch)Real pretraining on GPUs.
The book's run is a toy. This is the full-scale version, if you want it.
By the end of today, you'll be able to
  • Compute training and validation loss for a text model, and explain overfitting on a small dataset.
  • Write the pretraining loop, and explain warmup, cosine decay and gradient clipping.
  • Use temperature and top-k in your own generate function.
  • Load GPT-2's weights into your model and get sensible text.
How to use this page
  1. Scroll. The bar pinned at the top always says what the current step is and how to read it: Read Skim Revisit Checkpoint Build Task.
  2. Each phase opens with a Before you read box: the questions to read with, and a link to try the phase's checkpoint cold.
  3. The first step of each phase is a card from this hub, shown inline with its Prime and Study boxes. Most readings after it are outside pages that open in a new tab. A few load inline.
  4. Tick Done as you finish a step. Take a break after each checkpoint.
  5. Checkpoint answers stay closed until you open them. Each one says which source to reopen if you missed it.
