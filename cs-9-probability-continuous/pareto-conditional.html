Pareto distribution and conditional probability

Also called the power-law distribution, or Pareto type I. The cheat-sheet's problem is insured home values with density 3x−4 above 1: given a home is insured for at least 1.5, how likely is it under 2? That is a Pareto with tail index α = 3 and minimum 1.

In one breath

A Pareto variable never goes below a minimum xm, and its tail shrinks like a power, (xm/x)α, not exponentially. To condition on "at least a", keep only the probability above a and rescale it to 1: P(A | B) = P(A and B) / P(B). For a Pareto, what's left above a is the same shape again, just stretched by a.

In Python

def sf(x, alpha=3, xm=1):
    """Survival P(X > x) = (xm / x)^alpha for x >= xm."""
    return 1 if x < xm else (xm / x) ** alpha

def cond(a, b, alpha=3):
    """P(X < b | X >= a) = 1 - S(b)/S(a) = 1 - (a/b)^alpha."""
    return 1 - sf(b, alpha) / sf(a, alpha)

def simulate(n=10**6, seed=0):
    rng = random.Random(seed)
    kept = hits = 0
    for _ in range(n):
        x = (1 - rng.random()) ** (-1 / 3)  # inverse of 1 - x^-3
        if x >= 1.5:
            kept += 1
            hits += x < 2
    return hits / kept, kept

print(1 - Fraction(3, 4) ** 3, round(cond(1.5, 2), 6))
# → 37/64 0.578125
print(simulate())
# → (0.5778553612588803, 295882)

Time O(1) for the exact answer: two powers and a divide. The simulation is O(n) and only 29.6% of draws (8/27) survive the condition, so rejection wastes most of the work; sampling U−1/3 × 1.5 directly would give the conditional law with no waste.

Why it beats the alternatives

✗ Forget to divide

Report P(1.5 ≤ X < 2) = 37/216 ≈ 0.171. That is a share of all homes, not of the ones known to be at least 1.5.

✗ Ignore the condition

P(X < 2) = 1 − 1/8 = 0.875. Most of that mass sits between 1 and 1.5, which the question already ruled out.

✗ Model it as exponential

Same mean 1.5, but memoryless: P(X < 2 | X ≥ 1.5) = 1 − e−0.5/1.5 ≈ 0.283, and the chance of a home above 20 drops 77-fold.

✓ Ratio of survivals

1 − S(2)/S(1.5) = 1 − (3/4)³ = 0.578. No integral needed once S is known, and it shows the Pareto's signature: above any a, X/a is the same Pareto again.

Is Pareto always the right tail?

No. It fits the top of things like large losses or incomes, where each doubling of the threshold cuts the chance by the same factor (here 2³ = 8). It is a poor model for the bulk: it forces a hard minimum and puts its highest density right at it. In practice people often use a lognormal or gamma for the body and splice a Pareto on only above a threshold (general practice, not from the source).

Watch α. With α ≤ 2 the variance is infinite, so sample standard deviations never settle; with α ≤ 1 even the mean is infinite. And "heavy tail" is a statement about the far tail only: near the middle, as at x = 10 above, an exponential with the same mean can still be the larger one.
