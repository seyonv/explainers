Conditioning on a sum

Also called conditioning on the total, or "posterior of a count given an aggregate". The source guide's Associated Applications section has one: a driver and a passenger, each hospitalized with probability 0.3, each hospital loss uniform on [0, 1]; given that the total loss is under 1, how many were hospitalized on average? It states the problem without an answer. Solved here: 102/191 ≈ 0.5340.

Prime · 2 minutes before you read

The problem: Often you can't see how many events happened, only something about their total: the bill was small, the day's losses stayed under a threshold, total latency was low. Guessing the hidden count means reasoning backwards, and both common shortcuts (ignore the condition, or drop the zero case) give the wrong answer.

Where it fits: It runs the hierarchical model backwards (child → parent) with cs-8's Bayes table. The only new piece is the chance that n losses sum to under c, a convolution like cs-8's, here a simple volume.

In one breath

You don't see the count, only something about the total it produced. Treat each possible count as an explanation: weight it by how common it is, times the chance that that many losses would add up to what you saw, then rescale. The totals-side chance is the only new work, and for uniform losses it is a simple volume: P(n losses sum to under 1) = 1/n!.

In Python

from fractions import Fraction as F
from math import comb, factorial

def p_sum_below(n, c):
    """P(U1 + ... + Un < c) for iid U(0,1): the Irwin-Hall CDF."""
    return sum((-1) ** k * comb(n, k) * (c - k) ** n
               for k in range(int(c) + 1) if c - k > 0) / factorial(n)

def given_sum_below(p, people, c):
    """Rows (n, prior, likelihood, joint, posterior) given L < c."""
    rows = []
    for n in range(people + 1):
        prior = comb(people, n) * p ** n * (1 - p) ** (people - n)
        like = F(p_sum_below(n, c))
        rows.append((n, prior, like, prior * like))
    total = sum(r[3] for r in rows)        # P(L < c)
    table = [(n, pr, lk, j, j / total) for n, pr, lk, j in rows]
    return table, total

table, total = given_sum_below(F(3, 10), 2, F(1))
for n, pr, lk, j, post in table:
    print(f"N={n}  {float(pr):.2f} x {str(lk):>3}"
          f" = {float(j):.3f} -> {float(post):.4f}")
ans = sum(n * post for n, *_, post in table)
print(f"E[N | L<1] = {ans} = {float(ans):.4f}")
# → N=0  0.49 x   1 = 0.490 -> 0.5131
#   N=1  0.42 x   1 = 0.420 -> 0.4398
#   N=2  0.09 x 1/2 = 0.045 -> 0.0471
#   E[N | L<1] = 102/191 = 0.5340

Time O(m · c) · Space O(m) for counts 0..m: one Irwin–Hall CDF per row, each with at most ⌊c⌋ + 1 terms. Fractions keep 102/191 exact. code/conditional-on-sum.py also prints the threshold table, the L = 0.8 case and the simulation.

Why it beats the alternatives

✗ Ignore the condition

"Each loss is under 1 anyway, so the condition says nothing": E[N] = 0.6. It does say something: two losses add up, and half the time they pass 1.

✗ Drop the zero-loss row

Reading "total loss" as "there was a loss" leaves only N = 1 and 2: 0.51 / 0.465 = 1.097. But L = 0 < 1 counts, and it is the most likely case (0.49).

✗ Only simulate

106 accidents give 0.5345 ± 0.0006: a good check, but not the exact 102/191, and a rare condition (say L < 0.01) would throw away almost every draw.

✓ Condition on the count

Split by how many losses there are; each row then needs only the distribution of a sum of n losses. Three rows, one triangle area, exact answer.

Does this always reduce to 1/n!?

No. 1/n! is special to uniform losses and a threshold of 1 (the simplex under the diagonal). Other thresholds need the full Irwin–Hall CDF, other loss laws need their own convolution, and with many counts or a messy law it is easier to use the normal approximation (see the CLT card) or simulate. If you are told the total exactly, swap probabilities for densities (example B above): the point mass at L = 0 then drops out, and the answer jumps to 1.146.

The same "given the total" move has two famous closed forms (standard results, not in the source). Independent Poissons X ~ Pois(2), Y ~ Pois(3) given X + Y = 5 give X ~ Bin(5, 2/5), so P(X = 2 ∣ total 5) = 10 × 0.42 × 0.63 = 0.3456. For two iid exponentials with a known sum t, the first one is uniform on (0, t).

Understand and remember

  • The count N is hidden and only the total L is observed → treat each n as a hypothesis → weight = prior P(N = n) × likelihood P(Sn < c) → rescale by their sum P(L < c) → posterior; E[N | L < 1] = 0.51/0.955 = 102/191
  • n uniform losses sum to under 1 inside the corner simplex of the unit cube → its volume is 1/n! → likelihoods 1, 1, 1/2 → the two-person case is what the condition mostly rules out (0.09 → 0.047)
  • L = 0 is a real outcome when nobody is hospitalized → it satisfies L < 1 → dropping the N = 0 row (0.49, the likeliest) gives 1.097 instead of 0.534
  • Told the total exactly → P(L = 0.8) = 0, so use densities of Sn at 0.8 as likelihoods → the point mass at 0 drops out → the answer jumps to 47/41 ≈ 1.146
  • detail that matters Other thresholds need the full Irwin–Hall CDF Σ(−1)kC(n, k)(c − k)n/n! → O(⌊c⌋) terms per row → exact Fractions for any c in O(m·c)
