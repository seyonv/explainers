Weibull distribution and the gamma function

Also called the Weibull survival or time-to-failure model; the gamma function is the factorial extended to non-integers. The cheat-sheet files its rat-survival problem under "Gamma", but the density is a Weibull with shape 3 and scale 120 weeks. The gamma function only shows up in its mean.

In one breath

A Weibull lifetime has survival curve P(X > x) = e−(x/λ)k. The shape k sets whether the risk of dying falls (k < 1), stays flat (k = 1, the exponential), or rises with age (k > 1). One substitution, y = (x/λ)k, turns every integral you need into e−y for probabilities, or into the gamma function for the mean.

In Python

import math, random
K, LAM = 3, 120

def sf(x, k=K, lam=LAM):
    """P(X > x): substitute y = (x/lam)^k, integrand -> e^-y."""
    return math.exp(-(x / lam) ** k)

def moment(n, k=K, lam=LAM):
    """E[X^n] = lam^n * Gamma(1 + n/k), same substitution."""
    return lam ** n * math.gamma(1 + n / k)

def sample(rng, k=K, lam=LAM):
    """Inverse transform: solve 1 - F(x) = U for x."""
    return lam * (-math.log(1 - rng.random())) ** (1 / k)

rng = random.Random(0)
xs = [sample(rng) for _ in range(10 ** 6)]
p = sum(x > 100 for x in xs) / len(xs)
print(f"exact {sf(100):.6f} {moment(1):.4f}")
print(f"sim   {p:.4f}   {sum(xs) / len(xs):.2f}")
# → exact 0.560625 107.1575
#   sim   0.5602   107.11

Overlapα = 1 is the exponential, as is Weibull k = 1. That's the only place the two families meet.

Both use Γ, which is probably why the source filed the rat here: the gamma function appears in the Weibull's moments, the gamma distribution does not appear at all.

Why the substitution beats the alternatives (for E[X])

✗ Assume the mean is the scale

True only for k = 1. The rat's mean is 107.16, not 120: the density peaks at 104.8 and 63.2% die before 120, so the average sits below the scale.

✗ The tail formula E[X] = ∫P(X > x) dx

Valid, but it leaves ∫e−(x/120)3 dx, which has no elementary antiderivative. You end up at Γ anyway.

✗ Just integrate numerically

Simpson gives 107.1575, but only for these numbers, with a truncated range. It tells you nothing about the variance or another shape.

✓ Substitute, then read off Γ

Setting y = (x/λ)k gives every moment: E[Xn] = λnΓ(1 + n/k). Mean, variance and survival all come from one line.

Is a Weibull always the right lifetime model?

No. Its hazard only ever goes one way (always falling, flat, or always rising), so one Weibull can't fit the "bathtub" curve NIST describes for many products: early failures, a calm middle, then wear-out. Fitting each phase separately, or a mixture, is the usual workaround (our suggestion, not the source's). If the lifetime is the wait for the α-th of several random shocks, the gamma distribution is the natural model; if you have no reason to pick a shape at all, a nonparametric Kaplan–Meier curve avoids choosing one.

The source's density was simply given, so k = 3 is its assumption, not something fitted. Near-symmetric shape 3 is why the mean (107.16) and the median (106.20) almost coincide here.
