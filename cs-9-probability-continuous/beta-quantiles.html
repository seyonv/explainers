Beta distribution

Beta(α, β), written β(2, 5) in the source. A density on [0, 1], so it is the usual model for an unknown probability or proportion. The source guide's Beta section asks for the median and 95th percentile of Y ~ Beta(2, 5) and gives no answer; both are solved here by bisection.

In one breath

Beta(α, β) puts a hump somewhere on [0, 1]: α pulls it towards 1, β towards 0, and a larger α + β makes it narrower. There is no formula for its quantiles, but its CDF only ever rises, so you can find any percentile by halving an interval until it is tiny.

Why a binomial: Beta(2, 5) is the distribution of the 2nd smallest of 6 independent uniforms. "The 2nd smallest is ≤ y" means "at least 2 of the 6 land below y", and each lands there with chance y. The same trick gives any whole-number Beta(α, β) CDF as P(Bin(α + β − 1, y) ≥ α).

Worked example: Y ~ Beta(2, 5)

The long right tail drags the mean (0.2857) past the median (0.2644), which sits past the peak (0.2). That order, mode < median < mean, is what a right skew looks like.

The four summary numbers, two betas each

Think of Beta(α, β) as a belief about a rate. Start from the flat Beta(1, 1); each success adds 1 to α and each failure adds 1 to β. So Beta(2, 5) is "1 success, 4 failures seen", and Beta(20, 50) has the same 2 : 5 ratio with ten times the data (illustrative).

Hand trace: bisection on F

Start with [0, 1]. Evaluate F at the midpoint; if it is below the target p, the answer is to the right, so move lo up, otherwise move hi down. Each step halves the interval.

In Python

def pdf(y):
    return 30 * y * (1 - y) ** 4        # 30 = 6! / (1! * 4!)

def cdf(y):                             # P(Bin(6, y) >= 2)
    return 1 - (1 - y) ** 6 - 6 * y * (1 - y) ** 5

def quantile(p, F=cdf, tol=1e-10):
    lo, hi, steps = 0.0, 1.0, 0
    while hi - lo > tol:                 # F rises, so halve [lo, hi]
        mid = (lo + hi) / 2
        steps += 1
        if F(mid) < p:
            lo = mid                     # answer is to the right
        else:
            hi = mid
    return (lo + hi) / 2, steps

for p in (0.5, 0.95):
    q, k = quantile(p)
    print(f"p = {p}  -> y = {q:.5f} after {k} halvings")
# → p = 0.5  -> y = 0.26445 after 34 halvings
#   p = 0.95  -> y = 0.58180 after 34 halvings

Time O(log(1/tol)) CDF calls · Space O(1). Each call halves the interval, so 10⁻¹⁰ takes ⌈log₂ 10¹⁰⌉ = 34 calls, whatever p is. Any rising function works as F: the saved file passes a general whole-number beta CDF, and also prints the traces, the normal and Newton attempts below, and the simulation.

Why it beats the alternatives

✗ Normal approximation

mean + 1.645 sd = 0.2857 + 1.645 × 0.1597 = 0.5484. But F(0.5484) = 0.9297, so 7% of the mass is above it, not 5%. The beta is skewed; the normal is symmetric.

✗ Newton's method

Step y − (F(y) − p)/f(y). From 0.5 it reaches 0.5818 in 3 steps, but from 0.9, where f is tiny (0.0027), the first step jumps to −17.6, outside [0, 1], and never comes back.

✗ Simulate and sort

10⁵ draws give 0.5820: right to about 3 decimals. The standard error is √(0.95 · 0.05 / 10⁵) / f(0.5818) ≈ 0.0013, so each extra digit costs 100× more draws.

✓ Bisection on the CDF

It only needs F to rise, which every CDF does. It can't leave [0, 1], it never diverges, and it gains one bit per call: 34 calls for 10 digits.

Is bisection always the way?

For whole-number α and β in an interview, yes: the binomial-tail CDF is exact and bisection can't fail. With fractional α or β, the CDF is the regularised incomplete beta function, which has no polynomial form. You can still bisect, but each F call becomes a numerical integral (Simpson's rule on f works). Outside interviews, use a library: scipy.stats.beta.ppf or R's qbeta. If you need millions of quantiles, a few bisection steps to get close and then Newton (safe once you are near the root) should be much faster; that is an inference from the two traces above, not a measured result.

The beta is also the wrong model for some things. It lives on [0, 1] (rescale for a known range [a, b]), it has at most one hump, and it covers one rate. For shares of three or more categories, use its multi-category version, the Dirichlet. As a prior, it pairs with binomial data: a Beta(2, 5) prior plus 3 successes in 10 trials (illustrative) gives a Beta(5, 12) posterior, with mean 5/17 ≈ 0.294 and a 90% interval of (0.132, 0.484), from the same bisection.
