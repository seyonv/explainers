The normal distribution and Chebyshev's bound

Also called the Gaussian and the bell curve; Chebyshev is also spelled Tchebysheff. The source guide's Normal heading is empty, but its Applications section has a blood-pressure problem (15 readings) that uses both ideas: the normal's 68-95-99.7 rule and Chebyshev's "at least 1 − 1/k²" guarantee.

Prime · 2 minutes before you read

The problem: You have a mean and a standard deviation and need to say how much data lies near the mean. If the data are bell-shaped, the normal gives a sharp answer; if you don't know the shape, using the normal anyway can overpromise. You need both the estimate and the guarantee, and to know which one you're giving.

Where it fits: Last of the one-distribution cards. It makes the normal usable without tables (Φ via math.erf) and brings back cs-8's within-kσ comparison. The CLT, normal-approximation and sample-size cards all stand on Φ, and Chebyshev returns as their worst-case alternative.

In one breath

How much of a data set sits within k standard deviations of its mean? If the data are bell-shaped (normal), about 68%, 95% and 99.7% for k = 1, 2, 3. If you know nothing about the shape, Chebyshev still guarantees at least 1 − 1/k²: 75% for k = 2, 89% for k = 3. That is a weaker promise, but one that holds for every distribution.

normal: P(|Z| < k) = Φ(k) − Φ(−k) → 0.6827, 0.9545, 0.9973 for k = 1, 2, 3 Chebyshev: P((X−μ)² ≥ k²σ²) ≤ E[(X−μ)²] / (k²σ²) = 1/k² (Markov on (X−μ)²)

Chebyshev's proof is one line: apply Markov's inequality to the non-negative variable (X − μ)², whose mean is σ². That's why it needs a finite variance and nothing else.

In Python

import math, statistics as st

BP = [172, 140, 123, 130, 115, 148, 108, 129,
      137, 161, 123, 152, 133, 128, 142]

def norm_cdf(z):
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))

def chebyshev(k):                 # floor for ANY distribution
    return max(0.0, 1 - 1 / k**2)

ybar, s = st.mean(BP), st.stdev(BP)  # stdev divides by n - 1
for k in (1, 2, 3):
    c = sum(abs(x - ybar) <= k * s for x in BP)
    normal = norm_cdf(k) - norm_cdf(-k)
    print(k, f"{c}/15", f"{chebyshev(k):.3f}", f"{normal:.4f}")
# → 1 11/15 0.000 0.6827
#   2 14/15 0.750 0.9545
#   3 15/15 0.889 0.9973

Time O(n) · Space O(1) beyond the list: one pass for the mean, one for s, one per k to count. math.erf is accurate to double precision, so no table lookup and no scipy.

Why it beats the alternatives

✗ The 68-95-99.7 rule

Sharper, but only if the data are normal. For the three-point distribution −2, 0, +2 with probabilities 1/8, 3/4, 1/8 (sd = 1), only 75% lies strictly within 2 sd, not 95%.

✗ The range rule

A quick sketch of s, not a guarantee: 16 vs the true 17.10 here. It assumes bell-shaped data and a sample big enough to reach ±2 sd; one outlier moves it a lot.

✗ Markov's inequality

Uses only the mean of a non-negative variable: P(X ≥ 170.27) ≤ 136.07 / 170.27 = 0.799. True, but nearly useless next to Chebyshev's 0.25 for both tails combined.

✓ Chebyshev's bound

Needs only a mean and a variance, and holds for every distribution. The three-point example above hits it exactly, so no better bound exists without more assumptions.

Is Chebyshev always the one to use?

No. It's a worst-case floor, so for data that really are near-normal it's loose: it promises 75% within 2 sd when the true share is about 95%. If a histogram looks bell-shaped, or you're averaging many independent values (the central limit theorem), use the normal instead. For one tail only you can't just halve 1/k², because the distribution may be lopsided; Cantelli's inequality, P(X − μ ≥ kσ) ≤ 1/(1 + k²), gives 0.2 for k = 2 instead of 0.25.

Chebyshev also fails when the variance is infinite (a Pareto with shape ≤ 2), and it says nothing at all for k ≤ 1. Here it is applied to the sample itself with s, which still works: at most (n − 1)/(n k²) of the points can lie at k or more sample sd from ȳ (our derivation from the definition of s).

Understand and remember

  • Apply Markov to (X − μ)², whose mean is σ² → P(|X − μ| ≥ kσ) ≤ 1/k² → at least 1 − 1/k² within k sd for any shape with a variance → a guarantee, but loose for bell-shaped data (75% vs 95.45% at k = 2)
  • Normal data → the share within k sd is Φ(k) − Φ(−k) → 68.27%, 95.45%, 99.73% → an estimate that's only as good as the bell-shape assumption
  • Chebyshev is attained by the three-point law (−2, 0, +2 w.p. 1/8, 3/4, 1/8) → no better distribution-free bound exists → sharper answers must buy assumptions about shape
  • detail that matters Φ via math.erf is accurate to double precision → no z-table rounding (1.96 vs 1.95996) and no scipy → every later card in the course computes normal tails the same way
