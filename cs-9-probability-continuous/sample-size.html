How big a sample?

Also called sample-size planning, or choosing n for a margin of error. The source guide's last Associated Applications problem: Cassie knows gas mileage has an sd of 3.3 mpg and wants to be at least 95% sure her sample mean is within 1 mpg of the true mean. The source gives only the question.

Prime · 2 minutes before you read

The problem: Before you measure anything (latencies, conversion rates, mileage) you have to decide how many samples to take. Too few and your margin misses the target; "30 is enough" is a rule about the CLT, not about precision, and gives only 90% coverage for Cassie's cars.

Where it fits: Last card. It runs the CLT backwards: instead of asking how a total or mean behaves for a given n, it asks which n makes the sample mean precise enough. Chebyshev returns as the shape-free (and 5× costlier) alternative.

In one breath

A sample mean wobbles around the true mean with sd σ/√n, so its error shrinks like 1/√n. Pick the confidence you want, read its z off the normal, and solve zσ/√n ≤ E for n. Then round up, never down: n must be a whole number of cars, and rounding down misses the target.

The source's intended answer is n = 42. With the rounded z = 1.96 the square is 41.84; with the exact 1.95996 it is 41.83. Either way n = 42.

The four knobs, two examples each

Think of throwing darts: each throw scatters by σ, but the average of n throws scatters by only σ/√n. To halve the scatter of the average you need four times the throws.

In Python

import math

def norm_cdf(z):
    return 0.5 * (1 + math.erf(z / math.sqrt(2)))

def norm_ppf(p, lo=-10.0, hi=10.0):   # bisection, no scipy
    for _ in range(100):
        mid = (lo + hi) / 2
        lo, hi = (mid, hi) if norm_cdf(mid) < p else (lo, mid)
    return (lo + hi) / 2

def sample_size(sigma, margin, conf):
    z = norm_ppf(1 - (1 - conf) / 2)   # two-sided: 2.5% each tail
    return math.ceil((z * sigma / margin) ** 2), z

def coverage(n, sigma, margin):      # P(|mean - mu| < margin)
    return 2 * norm_cdf(margin * math.sqrt(n) / sigma) - 1

n, z = sample_size(3.3, 1.0, 0.95)
print(n, round((z * 3.3) ** 2, 2))
for m in (41, 42):
    print(m, round(coverage(m, 3.3, 1.0), 4))
# → 42 41.83
#   41 0.9477
#   42 0.9505

Time O(1): one bisection (100 steps) for z, then one formula. The full file also prints the table above, the Chebyshev answer and the simulation.

Why it beats the alternatives

✗ Rounding to the nearest

41.83 rounds to 42 here by luck; 41.3 would round to 41. Any n below the bound misses: n = 41 gives a 1.010 mpg margin and 94.77% coverage. Always round up.

✗ "30 is enough"

The rule of thumb is about when the CLT kicks in, not about precision. 30 cars give a 1.181 mpg margin and only 90.3% coverage.

✗ Chebyshev's bound

P(|X̄ − μ| ≥ E) ≤ σ²/(nE²) ≤ 0.05 needs n ≥ 10.89 / 0.05 = 217.8, so 218 cars. Guaranteed for any shape, but 5.2 times as many cars.

✓ (zσ/E)², rounded up

42 cars, 95.05% coverage by the normal and 95.03% / 95.11% in simulation for two shapes. The smallest n that meets the target.

Is 42 always the right answer?

Only if σ really is 3.3 and the sample mean is close to normal. The source treats σ as known. If Cassie instead estimates the sd from her own sample, the interval uses a t quantile, which is wider: with s = 3.3, n = 45 is the first size whose t margin is under 1 mpg (t0.975, 44 = 2.0154 gives 0.991; at n = 44 it is 1.003). A pessimistic σ is a common safety margin; if the true sd is 4, the same 42 cars give a 1.21 mpg margin.

It is also the wrong plan when the cars aren't a random, independent sample (one fleet depot, one driver, one season), because correlated cars add less information than their count suggests. For heavy-tailed data where σ is huge or undefined, fall back on Chebyshev's bound, on medians, or on a pilot study.

Understand and remember

  • Average n independent values → the mean's sd is σ/√n → margin at confidence z is zσ/√n → solve zσ/√n ≤ E → n ≥ (zσ/E)² = 41.83 → 42 cars
  • n scales as σ², z² and 1/E² → half the margin needs four times the sample; 99% costs 1.73× what 95% does → precision is expensive at the margin
  • Rounding down puts n below the bound → the margin exceeds E (1.010 mpg at 41) → coverage falls below target (94.77%) → always round up
  • The normal answer assumes the sample mean is near-normal and σ is known → Chebyshev assumes only a variance and needs 218 → estimating σ needs a t quantile (45 cars) → each assumption you drop costs samples
  • detail that matters For a proportion, σ = √(p(1 − p)) is at most 0.5 → plugging in the worst case gives a safe n without knowing p (1068 for ±3 points at 95%)
