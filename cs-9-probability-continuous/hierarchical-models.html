Hierarchical models

Also called two-stage, multilevel or mixture models; "conditioning on the parent". The source guide's Multivariate Distributions section poses two: a signal S ~ N(μ, σ2) received as R | S ~ N(s, 1), and an integer X from 0–4 followed by Y from 0 to x. It states both without solutions; both are solved here.

Prime · 2 minutes before you read

The problem: Many quantities are drawn in two stages: a true signal and then a noisy reading, a patient's risk and then an outcome, a day's load level and then each request. Finding the child's full distribution first means an integral that usually has no closed form, and forgetting the parent's spread makes a tail probability 8× too small (0.046 instead of 0.371 here).

Where it fits: It builds a joint from a parent and a child, the reverse of the joint-table card's slicing, and turns that card's tower check into the two rules this course leans on most. The MGF-of-a-product and conditioning-on-a-sum cards use the same move.

In one breath

A hierarchical model draws a random parent first and then draws a child whose distribution depends on it. You rarely need the child's distribution on its own: condition on the parent, answer the easy question for a fixed parent, then average over the parent. Two rules do this averaging, one for means and one for variances.

The two rules

E[R]= E[ E[R∣S]easy: S fixed ] Var(R)= E[Var(R∣S)]noise within a parent + Var(E[R∣S])spread between parents
Sthe parent: drawn first (the signal sent; X in the integer problem)N(μ, σ2) R∣Sthe child for one fixed parent (the signal received)N(s, 1) E[R∣S]a function of S, so itself random: here just S= S Var(R∣S)also a function of S: here the constant 1= 1
E[R] = E[S] = mu Var(R) = E[1] + Var(S) = 1 + sigma^2 Cov(R, S) = E[S * E[R|S]] - mu^2 = E[S^2] - mu^2 = sigma^2

Filled in with μ = 10, σ = 2 (illustrative; the source keeps the symbols): E[R] = 10, Var(R) = 1 + 4 = 5, Cov(R, S) = 4.

Simulating 106 signals (seed 0) gives E[R] 10.003, Var 4.996, Cov 3.997 and kurtosis 2.994 (a normal has 3). Step 8 is the reason statisticians like hierarchical models: the best guess for S is pulled from the reading back toward the population mean, by the share 1/5 of Var(R) that is noise.

Worked example 2: pick X, then pick Y up to X

The source says "make assumptions"; the natural ones are X uniform on {0, 1, 2, 3, 4} and Y | X = x uniform on {0, …, x}. Then each cell is P(x) × P(y | x) = 1/5 × 1/(x + 1). Green cells have x + y > 4; grey cells can't happen (y > x).

The words, two examples each

Think of a noisy phone line: first someone chooses what to say (the parent), then the line garbles it (the child). The two layers of randomness add up.

In Python

import math
from fractions import Fraction as F

def signal_moments(mu, sigma):
    """Tower rule + law of total variance for R = S + noise."""
    e_r = mu                       # E[E[R|S]] = E[S]
    var_r = 1 + sigma ** 2         # E[Var(R|S)] + Var(E[R|S])
    cov = sigma ** 2               # E[S * E[R|S]] - mu^2
    return e_r, var_r, cov, cov / math.sqrt(sigma ** 2 * var_r)

def two_dice():
    """X ~ U{0..4}; Y | x ~ U{0..x}. Joint pmf, exact."""
    return {(x, y): F(1, 5) * F(1, x + 1)
            for x in range(5) for y in range(x + 1)}

print(signal_moments(10.0, 2.0))
joint = two_dice()
ans = sum(p for (x, y), p in joint.items() if x + y > 4)
print(ans, float(ans))
# → (10.0, 5.0, 4.0, 0.8944271909999159)
#   13/50 0.26

Time O(n²) · Space O(n²) for the integer table with parent values 0..n−1: one exact fraction per reachable cell. code/hierarchical-models.py also prints the shrinkage, the variance split and both simulations (Python 3.10, about 4 s of CPU).

Why conditioning beats the alternatives

✗ Find R's density first

Integrate the joint density over s (a convolution) and then take moments. It works here, but it's the long way round, and for most two-level models the integral has no closed form.

✗ Use only the conditional variance

"The receiver adds noise of variance 1, so Var(R) = 1." That drops the spread of S. P(|R − 10| > 2) would be 0.046; the true value is 0.371.

✗ Only simulate

Two nested draws give 0.2598, not 13/50, and 106 runs still leave ±0.0004. Good as a check, but it won't tell you Cov(R, S) = σ2 for every μ and σ.

✓ Condition on the parent

Fix the parent, solve the easy one-level problem, then average with the tower rule and total variance. Each of the four source answers is one line.

Is the child always normal when both levels are?

No. R came out normal only because the parent moves the child's mean linearly and leaves its variance fixed, so R = S + independent noise. If the parent sets the variance instead, say R | V ~ N(0, V) with V equal to 1 or 9 with probability 1/2 each, then R is a mixture with kurtosis 3 × 41/25 = 4.92, not 3: heavier tails than any normal. The tower rule and total variance still hold; only the shape changes.

The answer to the integer problem depends on the assumptions. The source leaves them open, and the uniform choice is ours. If both draws were binomial with p = 1/2 instead (X ~ Bin(4, 1/2), Y | x ~ Bin(x, 1/2)), the same table gives 47/256 ≈ 0.184, not 0.26.

Understand and remember

  • Fix the parent → the child's problem is easy (R | S = s is N(s, 1)) → average over the parent with E[R] = E[E[R | S]] → E[R] = μ without ever finding R's density
  • Total spread = noise within a parent + spread between parents → Var(R) = E[Var(R | S)] + Var(E[R | S]) = 1 + σ² → dropping the second term turns P(|R − 10| > 2) from 0.371 into 0.046
  • The parent moves the child's mean linearly and leaves its variance fixed → R = S + independent noise → R is normal, N(μ, σ² + 1) → if the parent set the variance instead, R would be a mixture with kurtosis 4.92, not 3
  • Parent and child share the parent → Cov(R, S) = E[S·E[R | S]] − μ² = σ² → correlation σ/√(σ² + 1) → the best guess of S from a reading shrinks toward μ by the noise share 1/(σ² + 1)
  • detail that matters In the discrete X-then-Y problem each cell is P(x)·P(y | x) = 1/5 × 1/(x + 1) → exact Fractions give 13/50 in O(n²) cells → simulation only checks it

4 · Compare against what you already know

vs Binomial and beta-binomial: The beta-binomial is a hierarchical model too. What's the parent and the child there, and what does total variance say about why it's wider than a binomial?

Check
  • parent: p ~ Beta; child: the count | p ~ Bin(n, p)
  • Var = E[np(1 − p)] + Var(np): noise within a p plus spread of p between groups
  • the second term is the extra spread a plain binomial with the average p misses

vs Conditioning on a sum: This card goes parent → child; conditioning on a sum goes child → parent. What do you compute in each direction, and which one needs a normalising constant?

Check
  • forward: averages over the parent with the tower rule and total variance
  • backward: a posterior over the parent given something about the child (prior × likelihood, rescaled)
  • only the backward direction needs the evidence P(L < c) to normalise
