Build an LLM study plan · Day 2

Text → batches, then attention

Day 2 of the Build an LLM path: Raschka chapters 2 and 3. Turn raw text into training batches, then code attention from a version without weights up to multi-head causal attention. You've seen both on the LLM basics path; today you write them.

By the end of all of this, you'll be able to
  • Build a data loader that turns a text into (input, target) batches with a sliding window, and explain context length and stride.
  • Explain why one forward pass on n tokens gives n training examples.
  • Code self-attention, a causal mask and multi-head attention, and give the shape of every tensor.
The same routine every phase
  1. Prime (5 min): read the phase intro and the green Prime box of any card in it.
  2. Code, don't copy. Type each book listing, run it, and print the shapes.
  3. Revisit the LLM basics card linked under a step when the code stops making sense.
  4. Say it back at the end of each day, closed book, before checking.
